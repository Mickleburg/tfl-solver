# EXAM-2 — второй вопрос билета: детерминизм и LL-свойство

Замер по 255 вопросам (`python tools/exam_survey.py`) — что стоит
на втором месте в билете:

| тема | сколько из 85 |
|---|---|
| детерминированность | **48** |
| LL- или LR-свойство | 17 |
| КС-свойство | 15 |
| регулярность, замкнутость, моноид | по 1–2 |

Условие приходит в двух видах, примерно поровну: **грамматика**
(`S → aSSb | ba | Ab`) или **описание языка множеством**
(`{w₁aw₂ | |w₁|_a = |w₂|_b}`).

Оракулы: `tfl/cfg.py`, `tfl/pda.py`, `tfl/parse.py`, `tfl/pump.py`,
`tfl/approx.py`.

---

## Главное: спрашивают про язык, а не про грамматику

> «Проверить, **задаёт ли данная грамматика LL-язык**»

Это вопрос о языке. Грамматика может быть не-LL, а язык — LL, и наоборот
неверно рассуждать «в грамматике левая рекурсия, значит язык не LL».
Свойства `is_ll1()`, `is_lr0()`, `is_slr1()`, `is_deterministic()`
говорят **только про предъявленный объект**; функций
`language_is_ll1()` в проекте нет намеренно — этот вопрос неразрешим.

### Разобранный пример: билет 1, вопрос 2

> Проверить, задаёт ли данная грамматика LL-язык: `S → SabS | Sc | ε`

```python
from tfl.cfg import parse_cfg
from tfl.lang import from_cfg, from_regex, residual_growth

G = parse_cfg("S -> S a b S | S c | ε")
G.is_ll1()                       # False — левая рекурсия
residual_growth(from_cfg(G), max_prefix=6, suffix_len=5)
#   классов не меньше 3, кривая 1:3 2:3 3:3 4:3 5:3 6:3 — полка
```

Полка на трёх классах — язык похож на регулярный. Проверяем гипотезу:

```python
from_cfg(G).disagreements(from_regex("(ab|c)*", "abc"), 9)      # []
```

Расхождений нет: `L(G) = (ab|c)*`. Дальше два независимых довода, и оба
предъявляются в ответе:

1. **Язык регулярен, а всякий регулярный язык — LL(1).** Праволинейная
   грамматика по минимальному ДКА (`A → xB` для переходов, `A → ε`
   для допускающих) конфликтов не даёт: переход по `x` в ДКА
   единственный, а `FOLLOW(A) = {$}`, потому что нетерминал всегда стоит
   последним.
2. **Предъявляем саму LL(1)-грамматику** и проверяем её механически:

```python
H = parse_cfg("S -> a b S | c S | ε")
H.is_ll1()                            # True
from_cfg(H).disagreements(from_cfg(G), 9)      # [] — тот же язык
```

Ответ: **да, грамматика задаёт LL-язык**, хотя сама она не LL(1).
Попутно `H.is_lr0()` даёт `False` — и это согласуется: `ε` и `c` оба
в языке, беспрефиксности нет, а LR(0)-языки беспрефиксны.

## Маршрут «язык детерминирован?»

### Сторона «да»

Предъявить DPDA и проверить его детерминизм механически:

```python
from tfl.pda import PDA          # симуляция с бюджетом, проверка детерминизма
```

Это доказательство ровно в той мере, в какой верна конструкция, поэтому
её обязательно прогоняют фазз-тестом против предиката из условия.

**Лайфхак преподавателя** (`consa_rk2_2024.pdf`): не понял, детерминированный
или нет — строй произвольную грамматику или PDA, это гарантированные
2 балла. Заявить, что НPDA детерминированный, — 0 баллов; честно пометить
недетерминизм — 1 балл.

### Сторона «нет»

**Лемма Ю** — единственный механизированный способ опровергнуть DCFL:

```python
from tfl.pump import nondcfl_by_pumping

nondcfl_by_pumping(L, lambda p: ("a" * p + "b" * (p - 1), "b", "b" * (p + 1)))
```

Классический свидетель из лекции — `L = {aⁿbⁿ} ∪ {aⁿb²ⁿ}`,
пара `x = aⁿbⁿ⁻¹`, `y = b`, `z = bⁿ⁺¹`. Потолок здесь тот же, что
у всех лемм о накачке: «не выяснено» означает, что обобщение
на произвольное `p` пишет человек.

Порядок попыток, он же порядок падения ценности ответа:

1. не КС вообще (накачка, Огден) — сильнее всего;
2. не DCFL (лемма Ю) — 1 балл даже если не-КС доказать не удалось;
3. не LL, но DCFL — теряется всего 1 балл из 3.

## Маршрут «язык LL(k)?»

* **Регулярен ⇒ LL(1).** Первым делом стоит проверить регулярность:
  `residual_growth`, и если полка — искать ДКА. Это самый дешёвый
  положительный ответ.
* **Не DCFL ⇒ не LL.** Включения `LL(k) ⊊ LR(k) = DCFL` дают
  односторонний перенос: опровержение детерминированности опровергает
  и LL-свойство.
* **Беспрефиксность** отделяет LR(0) от остального DCFL и стоит +1 балл
  почти даром — проверяется `tfl/parse.py`.
* Приведение грамматики к LL(1) (устранение левой рекурсии и левая
  факторизация) — обычный путь к ответу «да», но требует доказать,
  что язык не изменился: `disagreements` на словах до длины 9–10.

## Регулярные аппроксимации сверху

Когда язык задан грамматикой и спрашивают про КС-свойство или
детерминизм, полезно пересечь язык с аппроксимацией:

```python
from tfl.approx import ...     # First/Follow-автомат, позиционный автомат
```

Вывод односторонний, и красная пометка преподавателя на проверенной
работе РК2 предупреждает именно об этом: пересечение «может привести
к переходу NCFL → DCFL в общем случае». Из «`L ∩ R` детерминирован»
не следует ничего про `L`.

---

## Границы выводов

| Что получено | Что доказано |
|---|---|
| `is_ll1()` вернул `True` | **эта грамматика** LL(1) ⇒ язык LL(1) |
| `is_ll1()` вернул `False` | **только про эту грамматику**, про язык ничего |
| построен и проверен DPDA | язык детерминирован (в меру верности конструкции) |
| лемма Ю дала `False` | предъявленная пара не работает, нужна другая |
| лемма Ю дала «не выяснено» | пара отбивает накачку при всех проверенных `p` — рабочий промежуточный результат |
| язык оказался регулярным | **язык LL(1)** |
| `L ∩ R` детерминирован | ничего про `L` |

## Чего не делать

* Не отвечать «не LL» на основании левой рекурсии в предъявленной
  грамматике — это свойство грамматики.
* Не называть построенный PDA детерминированным, не проверив: за это
  ставят 0, а за честную пометку недетерминизма — 1 балл.
* Не переносить свойство пересечения с регулярным на исходный язык
  в сторону «принадлежит классу».
* Не бросать задачу, если класс не определился: грамматика или PDA
  без вердикта — это всё равно 2 балла.

## Чек-лист

- [ ] Понято, спрашивают про язык или про грамматику.
- [ ] Проверена регулярность языка — это самый дешёвый ответ «да, LL».
- [ ] Если ответ «да» — предъявлена конструкция (LL(1)-грамматика, DPDA)
      и проверена фазз-тестом против предиката из условия.
- [ ] Если ответ «нет» — предъявлена лемма Ю с парой и рассуждением
      при произвольном `p`.
- [ ] Проверена беспрефиксность (+1 балл почти даром).
- [ ] Свойства грамматики нигде не выданы за свойства языка.
