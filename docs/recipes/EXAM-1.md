## Шаг 0. Записать условие предикатом

Всё остальное держится на этом. Условие вида
`{w₁w₂w₃w₄ | |w₂| = |w₄| & |w₁|_a = |w₃|_a}` переписывается прямо
как перебор разбиений:

```python
from tfl.lang import from_predicate

def free_split(w):
    n = len(w)
    return any((k - j) == (n - k) and w[:i].count("a") == w[j:k].count("a")
               for i in range(n + 1) for j in range(i, n + 1) for k in range(j, n + 1))

L = from_predicate(free_split, "ab")
```

Предикат пишется **по тексту условия** и потому независим от любой
конструкции, которую вы потом построите. На этой независимости держится
вся проверка: совпадение независимо написанных предиката и автомата —
довод, а совпадение «по построению» — нет.

## Шаг 1. Кривая роста числа классов

```python
from tfl.lang import residual_growth

verdict = residual_growth(L, max_prefix=8, suffix_len=8)
print(verdict.reason)
print(verdict.witness.markdown())
```

Для каждой длины `ℓ` берутся **все** слова этой длины и сравниваются
по вектору принадлежности `u·s ∈ L`. Разные векторы — доказанно разные
классы Майхилла–Нероуда, поэтому каждое число в кривой это честная
нижняя оценка.

| кривая | что делать дальше |
|---|---|
| `2 3 3 3 3 3 3 3` — полка | строить ДКА примерно на столько состояний |
| `2 3 4 5 6 7 8 9` — растёт | искать различающее семейство, автомата не будет |
| `2 3 5 7 13 21 41 75` — растёт быстро | то же самое, и семейство ищется тяжелее |

**Различать надо полку и рост, а не скорость роста.** У языка
`|w|_a = |w|_b` классов ровно `ℓ+1` на префиксах длины `ℓ` — рост линейный,
а язык нерегулярен. Проверка «удваивается ли» такие случаи пропускает;
`plateau()` смотрит именно на полку.

Вывод односторонний в обе стороны: рост доказывает нижнюю оценку, но не
бесконечность классов; полка не доказывает регулярность — горизонт
суффиксов конечен.

## Шаг 2а. Ловушка «свободного разбиения»

Если условие разрезает слово на части `w₁w₂w₃w₄`, ничем эти части
не ограничивая, кроме длин и счётчиков, **сначала проверьте, не входит
ли в язык вообще всё.** Квантор существования по разбиению даёт слишком
много свободы.

> **Билет 13 (пачка 1).** Проанализировать язык на регулярность:
> `{w₁w₂w₃w₄ | |w₂| = |w₄| & |w₁|_a = |w₃|_a}`, алфавит `{a,b}`.

```python
from tfl.words import iter_words
[w for w in iter_words("ab", 12) if not free_split(w)]     # []
```

Вне языка нет ни одного слова до длины 12. Доказательство: взять
`w₂ = w₄ = ε` и разрезать `w` на `w₁w₃` так, чтобы буквы `a` поделились
поровну. Если `|w|_a` нечётно, одну лишнюю `a` уводим в `w₂`, а в `w₄`
берём последнюю букву — длины по-прежнему равны. Язык — это `Σ*`,
и ответ «регулярен» пишется в одну строку.

Ошибка здесь стоит всей задачи: студент строит накачку для языка,
который равен `Σ*`.

## Шаг 2б. Условие на счётчики подслов

> **Билет 10 (пачка 1).** Является ли язык КС?
> `{w | |w|_aa = |w|_ba & |w|_bb = |w|_abb}`

```python
from tfl.lang import counter_dfa

counter_dfa({"ab": 1, "ba": -1}, "ab").value     # True — регулярен, ДКА в witness
counter_dfa({"aa": 1, "ba": -1}, "ab").value     # None — разность не ограничена
```

Состояние — пара «последние `k−1` букв, значение счётчика». Обход
конечен **ровно тогда**, когда разность ограничена, поэтому завершившийся
обход доказывает регулярность и выдаёт готовый ДКА.

Работает не всегда: у билета 10 обе разности не ограничены (`aⁿ` даёт
`n−1` вхождений `aa` и ни одного `ba`), обход упирается в бюджет, и приём
не применим. Это честный исход «не выяснено», а не ответ.

## Шаг 2в. Когда стандартные семейства не срабатывают

> **Билет 1 (пачка 1).** Проверить язык на регулярность:
> `{w | ∃v,u(|v| > 0 & w = vvᴿu ∨ w = uvvᴿ)}`

Условие читается как «у слова есть палиндромный префикс чётной длины
или палиндромный суффикс чётной длины». Естественная гипотеза «две
одинаковые буквы подряд по краю» **опровергается свидетелем**: `abba`
входит в язык (`v = ab`), а под гипотезу не подходит.

Кривая роста `2 3 5 7 13 21 41 75` полки не даёт — язык почти наверняка
нерегулярен. Но перебор шестидесяти четырёх пар шаблонных семейств
(`(ab)ⁿ`, `abⁿ`, `abⁿa`, `(ab)ⁿa`, …) **ни одной различающей пары
не нашёл**, и вот почему: семейство `(ab)ⁿ` против `(ba)ᵏ` различает
префиксы по признаку «палиндромный префикс», но те же слова попадают
в язык через **суффикс**, и различие схлопывается. Объединение двух
условий рушит семейства, работающие для каждого по отдельности.

Как есть, так и записывайте: нижняя оценка 75 классов доказана,
регулярность не опровергнута. Это наработка, а не решение.

## Шаг 3. КС-свойство (16 вопросов из 85)

Порядок попыток — от дешёвого к дорогому:

1. **Пересечь с регулярным** (`L.restrict("a*b*c*")`) и работать с простым
   языком. Вывод односторонний: из «`L ∩ R` не КС» следует «`L` не КС»,
   обратно — нет.
2. **Однобуквенный алфавит** — `tfl.lang.one_letter_noncf`: по теореме
   Париха над одной буквой регулярные и КС-языки совпадают, поэтому
   нерегулярность там сразу даёт не-КС.
3. **Накачка** — `tfl.pump.noncf_by_pumping` перебирает **все** разбиения.
4. **Лемма Огдена** — `tfl.pump.noncf_by_ogden`, когда обычная накачка
   не берёт: отмеченные буквы обязаны быть во всех трёх частях одной
   из двух троек.
5. **Числовой инвариант грамматики** — `CFG.counting_condition`, если язык
   задан грамматикой и условие числовое.

## Шаг 3а. µ-выражение

Билет 2022 начинается с «Описать язык µ-выражения
`µX.(a(µY.bX|Ya|(µZ.ZZ|cc))bX|ε)`». Определение — лекция 8 (2022):
`L(µX.r(X))` есть объединение `r(X)`, `r(r(X))`, …, а µ-оператор вместе
с регулярными операциями задаёт **в точности** класс КС-языков.

Отсюда весь приём: перевести в грамматику и дальше работать обычным
аппаратом.

```python
from tfl.mu import parse_mu

expression = parse_mu("µX.(a(µY.bX|Ya|(µZ.ZZ|cc))bX|ε)")
expression.to_cfg()      # X → aYbX | ε; Y → bX | Ya | Z; Z → ZZ | cc
expression.words(9)      # '', 'abb', 'abab', 'accb', 'abaab', …
expression.agrees_with(hypothesis, max_len=9)
```

Две тонкости разбора, каждая меняет язык:

* **тело `µ` тянется вправо до упора**: `µX.aXb | ε` — это
  `µX.(aXb | ε)`, а не `(µX.aXb) | ε`;
* **переменная — та, что связана `µ`**, а не та, что заглавная.
  В лекции переменные строчные (`µy.a(µx.axb + y + a)`), в билете
  заглавные; по регистру угадывать нечего.

Ответ на билет 2022, сверенный оракулом на всех 29 524 словах длины
до 9: $L = (a\,M\,b)^*$, где $M = (b L \cup (cc)^+) a^*$. Словами:
слово распадается на блоки `a … b`, внутри блока стоит либо `b` и снова
слово языка, либо чётное положительное число букв `c`, а за этим —
сколько угодно букв `a`.

Гипотезу пишет человек, совпадение проверяет `agrees_with`: расхождение
возвращается конкретным словом и указанием, кто из двоих его принимает.

## Шаг 4. Конструктивные задания

| Спрашивают | Чем делается |
|---|---|
| минимальный ДКА | `dfa_of(regex).minimized()`, минимальность — `class_table` |
| таблица классов эквивалентности | `tfl.myhill.class_table(...).to_markdown()` |
| регулярка для дополнения | дополнить ДКА, затем `tfl.regex` обратно в выражение |
| lookahead-регулярка → академическая | `tfl/afa.py`, конструкция из issue #40 |
| прообраз относительно морфизма | подстановка `h(x)` в переходах ДКА |
| синтаксический моноид | `tfl.monoid.syntactic_monoid(dfa)` |

Минимальный ДКА почти всегда просят **обосновать**, а не просто предъявить:
одна таблица классов даёт и минимальность ДКА, и нижнюю оценку на НКА
по треугольному критерию Глайстера–Шаллита (`extended_fooling_set`).

## Границы выводов

| Что получено | Что доказано |
|---|---|
| кривая роста упёрлась в `N` | **классов не меньше `N`** — и только это |
| кривая вышла на полку | ничего: горизонт суффиксов конечен |
| `counter_dfa` завершил обход | **язык регулярен**, ДКА в свидетеле |
| `counter_dfa` упёрся в бюджет | ничего про язык |
| предикат и построенный ДКА совпали до длины `N` | сильный довод, не доказательство |
| накачка или Огден дали `False` | **язык не КС** |
| накачка не сработала | ничего: у языка может не быть накачиваемого слова |

## Чего не делать

* Не строить накачку раньше, чем проверено, не равен ли язык `Σ*`.
* Не читать полку кривой как доказательство регулярности.
* Не переносить вывод с `L ∩ R` на `L` в сторону «принадлежит классу».
* Не доверять номеру вопроса в билете: тема за ним не закреплена.
* Не выдавать «ищите различающее семейство» за ответ — это наработка,
  и в отчёте она так и называется.
