# RK1-C — языки синтаксических объектов и древесные языки

Слова здесь — это тексты формальных объектов: формул, регулярных выражений,
грамматик, систем переписывания. Язык — множество *корректных* объектов
либо объектов *с некоторым свойством*.

Опора: условия `rk1_tfl_2025.pdf`, лекция 11 (древесные языки).
Оракулы: `tfl/tree.py`, `tfl/regex.py`, `tfl/srs.py`, `tfl/cfg.py`,
`tfl/lang.py`.

---

## Шаг 1. Понять, о чём язык: о строках или о деревьях

Это первое и главное развилочное решение. В условии стоит слово
**«древесный»** — тогда речь о деревьях, и **регулярность древесного языка
не то же самое, что регулярность языка его линейных записей**.

> **В4 2025.** Древесный язык логических формул со связками `∨`, `&`, `¬`
> над переменными `P` и `Q` такой, что в них нет подформул вида `Φ & Φ`.
> **В11.** Древесный язык всех логических формул со связками `¬`, `&`
> и булевскими константами, не содержащих двойных отрицаний.
> **В8.** Древесный язык регулярных выражений с бинарной конкатенацией
> и альтернативой, а также итерацией, не содержащих подвыражений `Φ* · Φ*`.
> **В14.** Формулы, в которых все бинарные операции сгруппированы влево.

Древесных задач много и, со слов преподавателя, будет больше.

## Шаг 2. Древесные языки

Древесный язык регулярен, если его распознаёт **детерминированный
восходящий древесный автомат**: состояние приписывается узлу снизу вверх,
исходя только из символа узла и состояний его детей. Роль суффикса играет
**контекст** — дерево с одной дырой.

### Если свойство локальное — стройте автомат

«Нет двойных отрицаний», «нет подвыражений `Φ* · Φ*`», «операции
сгруппированы влево» — всё это проверяется по узлу и состояниям детей,
значит хватает конечного числа состояний.

```python
from tfl.tree import TreeAutomaton, disagreements, parse_tree

SIGNATURE = {"P": 0, "Q": 0, "not": 1, "and": 2, "or": 2}
delta = {(leaf, ()): "ok" for leaf in ("P", "Q")}
delta[("not", ("ok",))] = "neg"          # перехода из neg нет — это ловушка
for op in ("and", "or"):
    for left in ("ok", "neg"):
        for right in ("ok", "neg"):
            delta[(op, (left, right))] = "ok"

automaton = TreeAutomaton(SIGNATURE, frozenset({"ok", "neg"}), delta)
disagreements(automaton, predicate, max_size=7)   # обязательно: должно быть []
```

Двух состояний хватает на В11, и запрет выражается **отсутствием перехода**,
а не отдельным состоянием-ловушкой. Прогон против условия обязателен:
красные пометки «автомат принимает лишнее» стоят ровно там, где его
не сделали.

### Если свойство требует сравнить поддеревья — язык не регулярен

«Нет подформул вида `Φ & Φ`» требует сравнить два поддерева целиком, а это
неограниченная информация. Доказательство равномерное и короткое: берём `n`
разных деревьев `t₁ … tₙ` и `n` контекстов `and(□, tᵢ)`. Тогда
`and(tᵢ, tⱼ)` нарушает условие ровно при `i = j`, то есть матрица
принадлежности имеет единственный минус на диагонали, и все `n` деревьев
попарно различимы.

```python
from tfl.tree import Context, HOLE, at_least_classes, parse_tree, trees

samples = trees(SIGNATURE, 4)[:6]
separators = [Context(parse_tree(f"and({HOLE}, {t})")) for t in samples]
at_least_classes(predicate, samples, separators)
# да: классов не меньше 6
```

Оракул даёт конечную оценку — точную и доказанную. Переход к `n → ∞` пишет
человек: конструкция равномерна по `n`, поэтому классов бесконечно много.

## Шаг 3. Строковые языки синтаксических объектов

> **В1 2025.** Язык академических регулярных выражений со скобками,
> принимающих все возможные слова в `a*`. Избыточные скобки допустимы.
> **В4.3.** Язык всех не конфлюэнтных (глобально) систем переписывания строк
> из одного правила. Алфавит `{a, b, →}`.
> **В14.2.** Язык регулярных выражений без скобок над `{a,b}`,
> не принимающих пустую строку.

Здесь язык — над алфавитом синтаксиса, и вопрос решается тем, **нужно ли
помнить неограниченно много**: вложенность скобок → нерегулярно; локальное
свойство соседних символов → регулярно.

**Ключевой ход: свойство объекта часто вычислимо по объекту одним из наших
оракулов.** Тогда предикат языка пишется в одну строку, и дальше работают
обычные приёмы `RK1-B`.

```python
from tfl.lang import from_predicate
from tfl.regex import parse
from tfl.automata import dfa_of, equivalent
from tfl.srs import parse_srs

def accepts_all_of_a_star(text: str) -> bool:
    try:
        tree = parse(text)
    except Exception:
        return False
    return equivalent(dfa_of(tree, alphabet="a"), dfa_of("a*", alphabet="a"))

L = from_predicate(accepts_all_of_a_star, "a*()|", "В1: регексы для a*")
```

Для В4.3 то же самое через `tfl/srs.py`: предикат «система из одного правила
не конфлюэнтна» считается оракулом, и остаётся вопрос регулярности **языка
записей**, а не свойства систем.

**Осторожно с неразрешимостью.** Конфлюэнтность в общем случае неразрешима,
поэтому `tfl.srs` возвращает `Verdict`, а не `bool`. Для предиката языка
годится только тот случай, где вердикт определённый; на «не выяснено»
слово в язык класть нельзя, и это ограничение надо оговорить в отчёте.

## Шаг 4. Предъявление и вторые представления

Разбалловка та же, что везде на РК1 (`docs/02-TASK-TAXONOMY.md`): платят
за **второе независимое представление**.

| Что предъявить | Инструмент |
|---|---|
| ДКА и регулярка (+1 за оба) | `tfl/automata.py` |
| таблица классов | `tfl.lang.table`, `tfl.myhill.class_table` |
| минимальный НКА с обоснованием | `tfl.myhill.extended_fooling_set` |
| синтаксический моноид (+1) | `tfl.monoid.syntactic_monoid` |
| древесный автомат | `tfl.tree.TreeAutomaton` |
| различающие контексты для деревьев | `tfl.tree.at_least_classes` |

## Границы выводов

| Вывод оракула | Что он значит |
|---|---|
| древесный автомат не расходится с условием до размера `N` | согласие на срезе; доказательством корректности не является |
| контексты развели `n` деревьев | **доказано**: классов не меньше `n` |
| контексты развели меньше, чем деревьев | **ничего**: контекстов не хватило, возьмите другие |
| предикат опирается на `Verdict` со значением `None` | слово не классифицировано — оговорить в отчёте |

## Чего не делать

* Не путать регулярность древесного языка с регулярностью его записей.
  Это разные вопросы, и ответы у них разные.
* Не предъявлять древесный автомат, не прогнав его против условия.
* Не строить предикат на неразрешимом свойстве молча: `tfl/srs.py`
  возвращает три исхода, и третий надо назвать.

## Чек-лист

- [ ] Определено, древесный язык или строковый.
- [ ] Для древесного построен восходящий автомат либо предъявлены
      различающие контексты.
- [ ] Автомат прогнан против условия, расхождений нет.
- [ ] Для нерегулярности показана **равномерная** по `n` конструкция,
      а не конечный набор примеров.
- [ ] Предъявлено второе независимое представление — это +1 балл.
- [ ] Случаи, где оракул сказал «не выяснено», названы явно.
