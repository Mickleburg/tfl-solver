# RK2-A — язык, заданный порождающим устройством и условием

**Задача 1 каждого варианта РК2.** Встречается в двух видах:

* **язык SRS над базисом** — «Язык SRS `ac→ca, c→bcb, bc→cb` над базисом `aⁿcaⁿc`»;
* **язык грамматики с числовым условием** — «Язык всех слов, порождаемых
  грамматикой `S→aSbS, S→aS, S→bab`, таких что в них ровно вдвое больше
  букв `a`, чем букв `b`».

Спрашивают одно и то же: описать язык, а дальше поместить его в иерархию.
Обычно требуется ещё предъявить автомат.

Оракулы: `tfl/srs.py` (замыкание, инварианты), `tfl/cfg.py` (остатки
линейного функционала), `tfl/lang.py`, `tfl/pump.py`.

---

## Вид 1: язык SRS над базисом

Определение: замыкание базиса по правилам,
$$L = \{\, w \mid \exists u \in B:\ u \Rightarrow^*_T w \,\}.$$

### Шаг 1. Посчитать замыкание — до конца

```python
from tfl.srs import parse_srs

T = parse_srs("ac -> ca\nc -> bcb\nbc -> cb")
found = T.closure([f"{'a'*n}c{'a'*n}c" for n in (1, 2, 3)], max_len=10)
found.exact          # False — обход упёрся в потолок длины
sorted(found.words)[:20]
```

**Самая частая ошибка класса.** На двух проверенных работах из девяти
преподаватель написала красным «**переписывание не исчерпывающее!**»
Замыкание считается перебором, а не «по смыслу правил»; глазом легко
не заметить композицию правил.

Помнить: `found.exact` почти всегда `False`, если есть удлиняющее правило.
Тогда полученное множество — **нижняя оценка** языка. Слова оттуда
в языке точно; отсутствие слова ничего не доказывает.

### Шаг 2. Найти инварианты

Инвариант — это то, что переживает любое переписывание, а значит
переносится с базиса на весь язык. Три источника:

```python
T.linear_invariants(modulus=2)   # точно, все инварианты Σ c_x·|w|_x mod m
T.length_is_monotone()           # не удлиняет ли переписывание
T.check_invariant(fn, words)     # метаморфная проверка произвольной гипотезы
```

Инварианты, которые реально встречались в работах:

| Инвариант | Где | Как доказывается |
|---|---|---|
| буква `b` встречается ровно один раз | вариант 13 | ни одно правило её не создаёт и не уничтожает |
| все `c` левее единственной `b` | вариант 13 | правила двигают их только влево |
| число букв `c` постоянно | photo_185 | правила `c` не создают |
| `2\|w\|_b − \|w\|_a` не убывает, на базисе ноль | вариант 28 | по правилу: `+0`, `+2`, `+1` |
| начальный блок из `a` не удлиняется | вариант 28 | ни одно правило его не наращивает |

Проверять инвариант надо **по правилам**, а не на выборке слов: перебрать
все слова до длины 7 и все их одношаговые переписывания. Тогда это
доказательство, а не наблюдение.

### Шаг 3. Свести базис к одному слову, если получится

Приём из photo_185: если из одного базисного слова добывается всё, что
даёт любое другое, разбирать надо только его. Там из первой же `c`
правилом `c→aca` получается произвольное число `a`, поэтому языки
из `aⁿcaⁿc` и `aᵐcaᵐc` совпадают, и достаточно взять `cc`.

Проверяется машинно: посчитать замыкания двух базисных слов и сравнить.

### Шаг 4. Описать язык и сверить

```python
from tfl.lang import from_predicate

L = from_predicate(гипотеза, "abc", "язык SRS")
[w for w in sorted(found.words) if w not in L]      # язык шире гипотезы
[w for w in L.words(8) if w not in found.words]     # гипотеза шире языка (или потолок)
```

Первый список обязан быть пустым. Второй — не обязан: там сидят и ошибки
гипотезы, и слова, до которых обход не дошёл. Разбирать их надо руками.

### Шаг 5. Иерархия

Дальше — общий приём курса: пересечь с регулярным, накачать. Эталон —
вариант 13 (работа на 5|5|5):

1. инварианты → точная форма достижимых слов `cⁿ a^{M(n)} b`;
2. рекуррентность → `M(n) = (n−1)·2ⁿ + 1` (экспонента);
3. пересечение с `c*a*b` изолирует чистое семейство;
4. накачка: соседние значения `M` отличаются на `n·2^{n−1} > p`.

## Вид 2: язык грамматики с числовым условием

### Шаг 1. Проверить, не пуст ли язык

Это первое, что надо сделать, и в двух вариантах из разобранных ответом
было именно «пусто». Условие вида «букв `a` вчетверо больше, чем `b`» —
это равенство `Σ c_x·|w|_x = 0`. Если найдётся модуль, по которому ноль
недостижим, язык пуст, и это **доказано**:

```python
from tfl.cfg import parse_cfg

g = parse_cfg("S -> a S b S b | a S a | a")
g.counting_condition({"a": 1, "b": -4})
# нет: по модулю 2 достижимы только остатки [1], нуля среди них нет
```

Считается неподвижной точкой по правилам, поэтому результат точен для всех
слов сразу. Обратное неверно: если противоречия не нашлось, вердикт —
«не выяснено», и язык скорее всего непуст.

Ручная версия того же (photo_116): `I(w) = |w|_a − 2|w|_b`; `S→a` даёт `1`,
`S→aSa` даёт `I+2`, `S→aSbSb` даёт `I₁+I₂−3` — всегда нечётно. А условие
`|w|_a = 4|w|_b` делает `I = 2|w|_b` чётным. Противоречие.

Закрывать такой ответ надо аккуратно: пустой язык **регулярен** (регвыражение
`∅`, ДКА из одного непринимающего состояния) и **КС**. Лемма о накачке
не нужна — так и написано в работе на полный балл.

### Шаг 2. Если язык непуст

```python
from tfl.lang import from_cfg

L = from_cfg(g)
[w for w in L.words(12) if условие(w)]
```

Дальше — как в виде 1: описать форму слов, пересечь с регулярным, накачать.
