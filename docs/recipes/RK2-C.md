# RK2-C — язык атрибутной грамматики

**Задача 3 каждого варианта РК2.** Дана грамматика с атрибутами и условиями,
надо описать порождаемый язык и ответить, регулярен ли он и контекстно-свободен.

Оракул — `tfl/attr.py`. Условия всех вариантов 2025 года лежат в
`corpus/txt/FormalLanguageTheory_2025_rk2_tfl_2025.txt`, разобранные работы
с баллами — в `reports/rk2-2026-photos/NOTES.md`.

## Как читать условие

```
S → S S   ;  S2.attr < S1.attr, S0.attr := S1.attr − S2.attr
S → b A   ;  S.attr := A.attr
A → b A b ;  A0.attr := A1.attr + 2
A → ε     ;  A.attr := 0
```

* `X0` — вхождение в **левой** части, `X1`, `X2` — в правой слева направо.
  Голое `X` — левая часть, если совпадает с ней, иначе единственное
  вхождение справа.
* `:=` — присваивание, всё прочее — **условие**.
* Слово в языке, если существует дерево вывода, где выполнены условия
  **всех** применённых правил.
* Атрибут, вычисляемый в `X0`, — синтезируемый (снизу вверх). Вычисляемый
  в `Xi`, `i ≥ 1`, — наследуемый (сверху вниз); тогда условие обычно стоит
  на правиле-листе, например `T → ε ; T.inh_attr == 0`.

## Порядок работы

### 1. Ввести грамматику в оракул

```python
from tfl.attr import parse_attr_grammar

g = parse_attr_grammar("""
S -> S S   ; S2.attr < S1.attr, S0.attr := S1.attr − S2.attr
S -> b A   ; S.attr := A.attr
A -> b A b ; A0.attr := A1.attr + 2
A -> a A b ; A0.attr := A1.attr + 1
A -> ε     ; A.attr := 0
""")
g.words(6)          # ['b', 'bab', 'bbb', 'babb', 'bbbb', 'baabb', ...]
```

Уже на этом шаге видно форму слов. Это **не ответ**, а материал для гипотезы:
перебор до длины 6 языка не описывает.

### 2. Выписать язык нижележащей КС-грамматики

Условия только отсеивают выводы, поэтому язык атрибутной грамматики всегда
вложен в язык `g.cfg()`. Часто нижележащая грамматика оказывается праволинейной
или сводится к регулярному выражению — тогда половина ответа готова.

Работа на 5 баллов (photo_187, вариант 1) делает именно это:
`B = b*`, `T = (b*a)*`, `S' = ((b*a)*a)*(b*a)*`, и всё вместе — просто `(b*a)*`.

### 3. Понять, что считает атрибут

Ключевой шаг. Атрибут почти всегда — это счётчик: число букв, число
применений конкретного правила, глубина вложенности. Гипотеза проверяется
одной строкой:

```python
g.check_attribute("A", "attr", lambda w: w.count("b"), max_len=8)
# да: совпало на N выводах длины ≤ 8
```

Осторожно: атрибут считает **применения правил**, а не буквы. В варианте 17
`A → baA` добавляет букву `b`, а атрибут не меняет — считаются только
применения `A → bbA`.

Для наследуемых атрибутов `check_attribute` честно отвечает «не выяснено»:
вне целого дерева у них значения нет.

### 4. Свести условие к арифметике

Подставив смысл атрибутов, условие превращается в неравенство на числа букв.
Дальше смотрим, не вырождается ли оно:

* **Часть условия недостижима.** Вариант 2: `(C.iter == 1 & T.free_a == T.a)`
  невозможно, потому что `C.iter ≥ 2`. Остаётся одна скобка.
* **Условие вырождает грамматику.** Вариант 16: `S₁.a₁ == S₁.a₂ + S₂.a₁`
  вынуждает правое поддерево быть тривиальным, и `S → bSbaS` схлопывается
  в `S → bSbaa`.
* **Условие требует точного квадрата** (вариант 9) — тогда язык не КС,
  и доказывается это не накачкой, а полулинейностью (теорема Париха)
  либо гомоморфизмом в унарный алфавит.

### 5. Сформулировать язык и сверить с оракулом

```python
g.disagreements(lambda w: гипотеза(w), max_len=7)   # ожидаем []
```

Пустой список — не доказательство, но непустой сразу закрывает вопрос.
**Гипотезу без этой проверки в отчёт не писать.**

### 6. Ответить на оба вопроса

**Регулярность.** Обычно нет, и доказывается таблицей Майхилла–Нероуда:

```python
from tfl import lang
L = g.language()
lang.at_least_classes(L, [«префиксы»], [«суффиксы»])
```

**Контекстная свобода.** Если язык — это (регулярное выражение) ∩
(линейное неравенство на числа букв), он КС: неравенство считается счётчиком,
а КС-языки замкнуты относительно пересечения с регулярным. Если условие
нелинейное (квадрат, произведение) — язык не КС.

Против КС в порядке возрастания хитрости:

1. накачка (`tfl/pump.py` — перебирает **все** разбиения);
2. пересечь с регулярным, накачать результат;
3. гомоморфизм в унарный алфавит + разрыв между соседними квадратами;
4. теорема Париха: образ Париха КС-языка полулинеен.

## Чего не делать

* **Не отбрасывать условие.** photo_115: студент решил задачу для нижележащей
  КС-грамматики, получил 1 балл. Условие и определяет язык.
* **Не выводить «язык КС» из того, что КС его пересечение с регулярным.**
  Прямая красная пометка преподавателя (photo_182): «оно может привести
  к переходу NCFL → DCFL в общем случае». Приём односторонний.
* **Не предъявлять свидетеля, не проверив, что он в языке** — две работы
  потеряли на этом баллы (photo_152, photo_189).
* **Не писать «при любом другом разбиении аналогично».** Пять красных пометок
  из девяти — именно про непройденные разбиения.

## Что оракул не умеет

* Доказать равенство языка гипотезе — только опровергнуть.
* Ответить про слово, если в грамматике есть цикл `A ⇒⁺ A` на том же отрезке
  **и** атрибуты наследуемые: деревьев бесконечно много, счёт по неподвижной
  точке для наследуемых не работает. Вердикт тогда — «не выяснено».
* Общего решателя полулинейности образа Париха по произвольному предикату нет
  и быть не может в таком интерфейсе. Практическое следствие для
  однобуквенного алфавита реализовано как `tfl.lang.one_letter_noncf`.
