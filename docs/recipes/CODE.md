# CODE — кодировки, морфизмы и переписывание образцов

Класс задач с семинара 05.09.2026 ([issue #44](https://github.com/TonitaN/FormalLanguageTheory/issues/44)):
восстановить кодирующие правила по строке, построить инъективную кодировку
с нужными свойствами, оценить задержку раскодирования, исследовать систему
переписывания **образцов** (правил с переменной).

Опора: условия семинара и разбор `reports/seminar-2026-09-05/report.md`.
Оракулы: `tfl/code.py`, `tfl/pattern.py`.

## Шаг 1. Однозначно ли декодируется

Первым делом — дешёвое достаточное условие:

```python
from tfl.code import Code

code = Code(("0", "01", "11"))
code.is_prefix_code()          # False — но это ещё ничего не значит
code.uniquely_decodable()      # True, и это доказательство
```

**Префиксность достаточна, но не необходима.** `{a, ab}` не префиксный
и при этом однозначный. Обратная ошибка — самая частая в этом классе.

Если префиксности нет, работает **алгоритм Сардинаса–Паттерсона**:
строятся множества висящих хвостов `S₁, S₂, …`, где `S₁` — непустые
остатки, на которые одно кодовое слово длиннее другого, а дальше
`Sₙ₊₁ = C⁻¹Sₙ ∪ Sₙ⁻¹C`. Код однозначен тогда и только тогда, когда ни одно
`Sₙ` не содержит кодового слова. Все хвосты — суффиксы кодовых слов,
их конечное число, поэтому процесс всегда останавливается.

Это **не перебор**. Перебор до длины `n` показывает лишь, что коллизий нет
среди коротких слов; разбор семинара это честно оговаривал, и теперь
оговорка снята.

При отрицательном ответе вердикт несёт свидетеля — слово с двумя разборами
(`{a, ab, ba}` → `aba = a·ba = ab·a`). В отчёт идёт именно он, а не
«алгоритм сказал нет».

## Шаг 2. Морфизм или нет

```python
from tfl.code import parse_morphism

h = parse_morphism("x -> 0; y -> 01; z -> 11")
h.is_injective()      # через тот же алгоритм: образы букв — это код
```

Инъективность морфизма равносильна однозначности кода из образов букв,
поэтому отдельной теории не нужно.

Если кодировка **не** морфизм, `tfl/code.py` не поможет: она задаётся
не таблицей букв. Пример из задачи 3 семинара — циклический сдвиг влево
`code(xu) = ux`. Такие проверяются прямо предикатом (инъективность —
перебором, негомоморфность — одним контрпримером: `code(ab) = ba`,
а `code(a)code(b) = ab`).

## Шаг 3. Задержка раскодирования

Сколько символов кода надо прочесть, чтобы понять первую букву прообраза.

```python
h.delay(6)           # (11, ('xzzzzz', 'yzzzzz')) — длина и пара-свидетель
h.delay_growth(7)    # [1, 3, 5, 7, 9, 11, 13]
h.bounded_delay(7)   # вердикт с кривой
```

Кривая читается так же, как кривая роста числа классов в `tfl/lang.py`:
**различать надо полку и рост, а не скорость**. Вышла на полку — задержка,
похоже, ограничена; растёт — похоже, нет. Ни то, ни другое срезом
не доказывается, и вердикт всегда «не выяснено».

Для ответа на задачу «морфизм с неограниченной задержкой» кривой мало:
нужна явная серия. У `x ↦ 0`, `y ↦ 01`, `z ↦ 11` она такая: `h(xzᵏ) = 0·1²ᵏ`
и `h(yzᵏ⁻¹) = 0·1²ᵏ⁻²`, общий префикс растёт линейно, а отличить `x` от `y`
можно только по чётности числа единиц — то есть дочитав до конца.

## Шаг 4. Системы переписывания образцов

Правило `aXb → bXa` обычной SRS не выразить: переменная покрывает
произвольный кусок слова.

```python
from tfl.pattern import parse_patterns

P = parse_patterns("aXb -> bXa\nXb -> aaX", variables="X")
P.step("abb")            # {'aaab', 'abaa', 'bab', 'bba'}
P.normal_forms("abb")    # {'aaaaa'}
```

Переменные **объявляются явно** — по той же причине, что в `tfl/trs.py`:
в корпусе встречаются обе договорённости о регистре.

Завершимость и конфлюэнтность в общем виде не решаются, поэтому оракул
играет роль арбитра при **предложенных человеком** мере и инварианте:

```python
P.check_invariant(lambda w: w.count("a") + 2 * w.count("b"), words)
P.check_measure(lambda w: (w.count("b"), sum(i for i, c in enumerate(w) if c == "b")), words)
P.confluent_on(words)
```

Так семинар задачу и разбирал: мера `(|w|_b, Σ позиций b)` в лексикографическом
порядке убывает на каждом шаге, инвариант `μ(w) = |w|_a + 2|w|_b` сохраняется,
а значит нормальная форма единственна и равна `a^μ(w)`.

Оговорка в вердикте стоит не для красоты: **фундированность меры оракул
не проверяет**. Убывание на конечном срезе плюс фундированность даёт
завершимость; фундированность обосновывает автор меры.

## Шаг 5. Моделирование образца строковой системой

Приём семинара: завести **маркер-долг**, который ходит по слову
на произвольное расстояние и тем изображает переменную.

```text
b → Ma      правило 1: b становится a, влево уходит долг M
aM → Ma     M проходит мимо a
bM → Mb     M проходит мимо b
aM → b      гашение: a становится b, M исчезает
```

Недетерминизм здесь намеренный: `aM → Ma` и `aM → b` применимы
одновременно, и это ровно свобода выбора `X`.

Сверка обязана быть **в обе стороны**, и оракул её делает:

```python
P.agrees_with_srs(srs, words, wrap=lambda w: f"^{w}$", max_len=7)
```

Две ловушки, каждая даёт ложное расхождение:

* в сравнение идут **только чистые строки** — с недогашенным маркером
  (`^Ma$`) строка промежуточная, а не достижимая;
* **потолок длины у обеих сторон одинаковый**. Строковой системе нужен
  запас на маркеры, поэтому её обход идёт дальше, но сравниваются слова
  не длиннее общего потолка — иначе «расхождением» окажется разница
  границ, а не языков.

## Границы выводов

* `uniquely_decodable` — единственный вердикт этого класса, который
  **доказывает**. Всё остальное считается на срезе.
* Задержка на срезе — наблюдение. Неограниченность доказывается серией,
  а не кривой.
* `confluent_on` не возвращает `True` никогда: единственность нормальной
  формы на конечном множестве слов конфлюэнтностью не является.
* Мера проверяется на убывание, но не на фундированность.

## Чего у нас нет

* **Восстановление кодирующих правил по строке** (задача 1 семинара) —
  содержательный шаг, его делает человек. Оракул проверяет предъявленный
  ответ: раскодировать, посчитать вложенность и типы термов.
* **Критические пары для образцов.** Наложение двух правил с переменными
  — это унификация образцов, её нет.

## Чек-лист

- [ ] Префиксность проверена первой (дёшево) и не выдана за необходимую.
- [ ] Однозначность — Сардинасом–Паттерсоном, а не перебором.
- [ ] При неоднозначности предъявлено слово с двумя разборами.
- [ ] Задержка: приведена кривая **и** явная серия, если утверждается
      неограниченность.
- [ ] Для образцов: мера и инвариант предъявлены явно и проверены
      исполнением; фундированность меры обоснована словами.
- [ ] Моделирование сверено в обе стороны, с одинаковым потолком длины.
