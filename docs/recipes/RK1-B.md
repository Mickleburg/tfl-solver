## Шаг 0. Записать предикат и сверить его с условием

Предикат пишется руками, и это единственное место, где ошибка стоит всей
задачи. Кванторы под чертой — источник большинства ошибок: в записи
`{w₁ z w₂ z | …}` части стоят под **существованием**, поэтому язык обычно
шире, чем кажется.

```python
from tfl.lang import from_predicate

L = from_predicate(predicate, "abc", "язык из условия")
sorted(L.words(6))[:20]      # глазами сверить с выписанными вручную словами
```

## Ветка 1. Счётчики подслов

> **В4 2025.** `{w | |w|_ab = |w|_bb & |w|_aaa ≠ |w|_aa & w ∈ {a,b}⁺}`
> **В6.** `{w₁w₂ | |w₁|_ab = |w₁|_ba & |w₂|_ab = |w₁|_a}`
> **В12.** `{w | |w|_aba = |w|_bab & |w|_ba = |w|_bb}`

Ключевое наблюдение курса: **равенство счётчиков часто регулярно**, потому
что разность структурно ограничена. Классика — `|w|_ab` и `|w|_ba`
различаются не более чем на 1, а `|w|_a` и `|w|_b` — на сколько угодно.

Приём формализован: состояние — пара «последние `k−1` букв, текущее
значение счётчика». Обход достижимых состояний конечен **ровно тогда**,
когда разность ограничена, поэтому завершившийся обход — это доказательство.

```python
from tfl.lang import counter_dfa, counter_range

counter_range({"ab": 1, "ba": -1}, "ab")   # быстрая диагностика: размах по длинам
verdict = counter_dfa({"ab": 1, "ba": -1}, "ab")
verdict.value                              # True — регулярность доказана
machine = verdict.witness                  # готовый ДКА, 5 состояний
```

`counter_range` показывает размах разности по длинам `4, 6, 8, 10, 12`.
Постоянный размах — признак ограниченности, и тогда `counter_dfa` это
докажет. Растущий — приём не применим, и вердикт честно говорит «не
выяснено», а не «нерегулярен».

Измерено оракулом:

| Условие | Размах по длинам 4…16 | Итог |
|---|---|---|
| `\|w\|_ab = \|w\|_ba` | 2, 2, 2, 2, 2, 2, 2 | ограничена ⇒ **регулярен**, ДКА из 5 состояний |
| `\|w\|_aaa = \|w\|_aa` | 1, 2, 3, 3, 4, 5, 5 | растёт ⇒ приём не берёт |
| `\|w\|_aba = \|w\|_bab` | 2, 4, 4, 6, 8, 8, 10 | растёт ⇒ приём не берёт |
| `\|w\|_ab = \|w\|_bb` | 5, 8, 11, 14, 17, 20, 23 | растёт ⇒ приём не берёт |

Если приём не взял — идём к таблице классов и накачке:

```python
from tfl.lang import family, at_least_classes, table
from tfl.pump import nonregular_by_pumping

at_least_classes(L, family(lambda i: "ab" * i, 8), family(lambda j: "b" * j, 8))
nonregular_by_pumping(L, lambda p: "a" * p + "b" * p)
```

**Конъюнкция условий разбирается по частям.** Каждый конъюнкт — отдельный
язык; пересечение регулярных регулярно. Достаточно, чтобы один конъюнкт
оказался нерегулярным, — но осторожно: пересечение нерегулярного
с регулярным бывает регулярным, так что вывод в эту сторону не проходит.

## Ветка 2. Повторяющиеся подслова

> **В1 2025.** `{w zᴿ v z | |w| > 1 & |z| ≥ 1 & (v = wᴿ ∨ v ∈ (ab)⁺)}`
> **В3.** `{w₁w₂w₃ | w₁ = w₃ ∨ |w₂|_a = |w₃|_a}`
> **В13.** `{w₁w₂w₁w₃w₂ | |w₁| > 0, |w₂| > 0}`

Здесь работает разбор задачи I, и он даёт **готовую методику выбора
свидетеля**. Смотрим на алфавиты частей:

> * словарь `v₁` отличается от словаря смежного с ним слова `z`. Значит,
>   если взять первую букву `z` из разности языка `z` и языка `v₁`,
>   то никакое значение `v₁` не сможет её поглотить;
> * словарь `v₂` точно такой же, как у смежных вхождений `z`. Поэтому `v₂`
>   может поглотить любой суффикс первого вхождения `z`, а также любой
>   префикс второго.

Отсюда три правила выбора свидетеля:

1. **Начать повторяемый блок буквой, которой нет в соседней части** —
   тогда её нельзя поглотить.
2. **Сделать положение блока однозначным** — например, поставить ровно
   два вхождения этой буквы на всё слово.
3. **Не брать блок с ненулевой префикс-функцией.** Прямое предостережение
   разбора:

   > В этой задаче не стоит брать значения `z`, значение префикс-функции
   > у которых больше, чем 0 (и осторожнее с такими словами в других
   > задачах).

   Причина: если `z` имеет собственную границу (как `cⁿ`), почти весь его
   суффикс уходит в `v₂`, слово остаётся в языке при любом сдвиге,
   и различить префиксы не выйдет.

Итоговый свидетель разбора — `c a^{n+2} c a^{n+2}`. Пара `c a^{m+k} c a^m ∈ L`
и `c a^m c a^{m+k+1} ∉ L` даёт нижнетреугольную матрицу принадлежности
(проверено, `tests/test_rk1.py`).

Дальше три независимых пути, и **любые два из них дают +1 балл**:

* **таблица классов** — `at_least_classes` на семействе `c aⁱ`;
* **пересечение с регулярным и накачка** — пересечь с `ca*ca*`, тогда
  качать можно только блок из `a`, и отрицательная накачка выводит из языка;
* **прямая накачка** — самый неприятный путь, два случая разбора.

```python
from tfl.pump import nonregular_by_pumping
nonregular_by_pumping(L.restrict("ca*ca*"), lambda p: "c" + "a"*(p+2) + "c" + "a"*(p+2))
```

Пересечение с регулярным — приём **односторонний**: из «`L ∩ R` не лежит
в классе» следует «`L` не лежит», обратный вывод неправомерен.

## Ветка 3. Гомоморфизмы

> **В6 2025.** `{w₁ v w₂ | w₂ = h(w₁) & |v| < |w₁|}`, `h(a) = aa`, `h(b) = a`.
> **В8.** `{w₁w₂w₃ | w₁ = h(w₃)}`, `h(a) = aa`, `h(b) = ab`.

Регулярные и КС-языки замкнуты относительно гомоморфизма и его обращения,
поэтому условие вида `w₂ = h(w₁)` не добавляет выразительной силы само
по себе — сложность даёт **совпадение**, а не морфизм. Смотреть надо
на то, стирающий ли `h` (`h(a) = ε` ломает длины) и различает ли он буквы:
`h(a) = aa`, `h(b) = a` не различает, и это обычно и есть суть варианта.

## Скобочное представление по Хомскому–Шютценберже (+2 балла)

Разбалловка (issue #21) отдельной строкой платит «+2 за скобочное
представление в стиле Шютценберже» — сверх КС-грамматики. Это **другое**
представление того же языка, а платят именно за независимость.

Теорема (лекция 8, 2021): любой КС-язык есть `h(PARENₙ ∩ R)`, где
`PARENₙ` — язык Дика над `4n` скобками, `R` регулярен, `h` гомоморфизм.
Построение по грамматике в НФ Хомского с пронумерованными правилами:
`A → BC` даёт `A → [ₙB]ₙ(ₙC)ₙ`, а `A → a` даёт `A → [ₙ]ₙ(ₙ)ₙ`.

```python
from tfl.cfg import parse_cfg
from tfl.schutzenberger import bracketed

representation = bracketed(parse_cfg("S -> A X | A B\nX -> S B\nA -> a\nB -> b"))
print(representation.markdown())        # нумерация, G′ и гомоморфизм
representation.agrees_with_source(40)   # h(L(G′)) = L(G) — главная проверка
representation.check_theorem(16)        # L(G′) = PARENₙ ∩ R
```

Пустое слово скобками не порождается: если ε в языке есть, его разбирают
отдельно, `L = h(L(G′)) ∪ {ε}`.

### Две поправки к лекции, найденные оракулом

**Гомоморфизм.** Лекция пишет: «Если `n` — нефинальное правило, то
`h([ₙ) = h(]ₙ) = h((ₙ) = h()ₙ) = ε. Иначе `h([ₙ) = a, для остальных
скобок так же». Буквальное «так же» даёт `h([ₙ]ₙ(ₙ)ₙ) = aaaa` вместо `a`.
В букву переходит **одна** скобка, остальные в ε.

**Регулярное условие.** Напечатанное на слайде 9 условие («слово
начинается с `[ₙ` для правила стартового нетерминала, и все `]ₙ`
предшествуют `(ₙ`») равенства `L′ = R ∩ PARENₙ` не даёт. Контрпример
нашёлся на грамматике из одного правила `S → a`: слово `[₁[₁[₁]₁]₁]₁`
скобочно правильно, начинается с `[₁`, а требование про порядок выполнено
впустую — `(₁` в слове нет вовсе. Свойства со слайдов 7-8, в определение
`R` не вошедшие, дыру тоже не закрывают.

Достаточно добавить три локальных требования: за `]ₙ` обязана идти `(ₙ`;
скобки согласованы по нетерминалам (за `[ₙ` для правила `A → BC` идёт
`[ₚ` только с левой частью `B`); слово кончается на `)ₙ`. Все три
локальные, `R` остаётся регулярным. `check_theorem` по умолчанию берёт
именно этот уровень (`level="строгое"`), а `level="слайд-9"`
воспроизводит дыру.

**В отчёт годится и лекционная запись**: спрашивают представление,
а не формальную выкладку про `R`. Но если `R` выписывают явно, писать
надо усиленный вариант.

## Границы выводов
