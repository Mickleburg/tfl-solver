# RK1-A — языки пар, чисел и трасс

Объекты с внутренней арифметикой или порождающей структурой: пара строк,
записанная в два ряда; число в позиционной записи; трасса вывода грамматики.
Вопрос всегда один — **регулярен ли язык**.

Разбалловка — `docs/02-TASK-TAXONOMY.md`, §«Разбалловка РК1». Ключевое:
платят за **второе независимое представление**, а не за ответ.

Опора: авторский разбор `2023/RK1_probe_task_solutions.pdf` (задачи II–IV),
условия `rk1_tfl_2025.pdf`. Оракулы: `tfl/automata.py`, `tfl/myhill.py`,
`tfl/monoid.py`, `tfl/lang.py`.

## A1. Язык пар строк

Условие записано в два ряда — верхний `x₁…x_k`, нижний `y₁…y_k`:

> **В1 2025.** `xᵢ, yᵢ` — буквы в `{a,b}`, и `x₁…x_k y₁…y_k` есть куб.
> **В2.** `xᵢ, yᵢ` — троичные цифры и `x₁…x_k = (y₁…y_k)²`.
> **В7.** `x₁…x_k = y_k…y₁`.
> **В13.** `xᵢ, yᵢ` — двоичные цифры, `x₁…x_k = 3·(y₁…y_k)`.

Это язык **отношения**: алфавит — пары символов. Строим автомат на парах,
при необходимости берём проекцию.

> Автомат-проекция указанного ДКА по первому компоненту также будет
> детерминированным (вообще говоря, **это не гарантируется** для проекций).

### Как найти множество состояний, а не угадать его

Главный приём разбора задачи II — **ограничить величину и доказать, что
за границей всё ведёт в ловушку.** Для `x = 5y` в троичной записи:

* пусть `x − 5y = k`. Максимальный выигрыш в пользу `x` за один разряд —
  дописать `2` к `x` и `0` к `y`: новое значение `3k + 2`. Оно `≤ k`
  при `k ≤ −1`, значит все пути с такой разностью тупиковые.
* максимальный выигрыш в пользу `y` — дописать `0` и `2`: новое значение
  `3k − 10`. Оно `≥ k` при `k ≥ 5`, снова тупик.
* значит в живых состояниях `x − 5y ∈ [0, 4]`, и дальше построение —
  техническая процедура.

Это готовый шаблон: выписать два крайних шага, решить два неравенства,
получить диапазон. **Обоснование конечности состояний — обязательная
часть решения**, без него автомат выглядит угаданным.

## A2. Числа в позиционной системе

> «Троичные числа, кратные 5», «числа по основанию 4, делящиеся на 5».

Автомат остатков: состояние — остаток, переход `r → r·base + d mod m`.

```python
from tfl.automata import DFA

delta = {(r, d): (r * 3 + int(d)) % 5 for r in range(5) for d in "012"}
machine = DFA(frozenset("012"), 0, frozenset({0}), delta)
```

Разбор доводит эту задачу до конца тремя предъявлениями, и все три у нас
механизированы:

```python
from tfl.myhill import class_table, extended_fooling_set
from tfl.monoid import syntactic_monoid

print(class_table(machine).to_markdown())        # минимальность ДКА
extended_fooling_set(machine)                 # нижняя оценка на НКА
print(syntactic_monoid(machine).markdown())   # +1 балл на задаче 2
```

Одна таблица классов даёт **два** результата сразу:

> Она не только свидетельствует, что построенный ДКА минимален,
> но и обосновывает, что никакой НКА для этого языка не может иметь
> меньше 5 состояний (согласно расширенному критерию Глайстера–Шаллита,
> нижняя граница на число состояний в НКА — число строк
> в верхнетреугольной матрице).

**Про регулярку.** Если минимальный ДКА оказался полным графом переходов,
регулярка будет экспоненциально длинной, и это надо сказать прямо, а не
пытаться её выписать:

> Мы имеем дело именно с таким языком, когда представление в форме ДКА
> оказывается экспоненциально более выгодным, чем в форме регулярного
> выражения (как минимум, при применении алгоритма устранения состояний
> напрямую).

## A3. Язык трасс грамматики

Слово — последовательность применений правил; алфавит `Σ ∪ {Nᵢ} ∪ {→} ∪ {;}`.

**Приём: разложить в пересечение двух регулярных языков.**

* `R₁` — «трасса составлена из правил именно этой грамматики»:
  `(N₁→Φ₁ | … | N_k→Φ_k ;)* (M₀→ε | … | M_s→ε)`.
* `R₂` — «раскрывается именно тот нетерминал, который был порождён»:
  `S→.?(N₁.?; N₁→.? | … | N_k.?; N_k→.?)* ε`, где `.?` — необязательный
  один символ.

Корректные трассы — это `R₁ ∩ R₂`. Строить регулярку напрямую не надо:

> Определять язык корректных трасс путём явного описания регулярного
> выражения было бы намного труднее: пришлось бы ветвить регулярное
> выражение по всем возможным переходам от одного нетерминала к другому.
> В худшем случае это привело бы к экспоненциальному росту.

```python
from tfl.automata import dfa_of, intersection, equivalent
machine = intersection(dfa_of(R1), dfa_of(R2))
```

**Когда трассы нерегулярны.** Если грамматика умеет **накапливать**
нетерминалы в сентенциальной форме, язык трасс нерегулярен. Доказательство
из разбора задачи IV — счёт по суффиксу, а не разбор случаев:

> Каждая итерация `S₁S₁; S₁→SS; S→` порождает минимум три вхождения буквы
> `a` в суффикс трассы. Возьмём `i = |P|`, тогда суффикс `P` должен
> содержать как минимум `3·(|P|·k + m)` букв `a`, а его длина явно меньше.

Приём общий: показать, что накачка префикса требует от суффикса больше
символов, чем в нём есть. Для таблицы классов суффиксы придётся выписать
явно — кратчайшие пути разбора накопленных нетерминалов.

## Границы выводов

| Вывод оракула | Что он значит |
|---|---|
| обход состояний завершился | **доказано**: язык регулярен, ДКА — свидетель |
| таблица различила `n` префиксов | **доказано**: классов не меньше `n` |
| `extended_fooling_set` дал `n` пар | **доказано**: в любом НКА не меньше `n` состояний |
| проекция ДКА оказалась детерминированной | повезло; в общем случае не гарантируется |
| свидетель отбил накачку при `p ≤ N` | **ничего**: нужен произвольный `p` |

## Чек-лист

- [ ] Для автомата на парах **обосновано**, почему состояний конечно много,
      а не просто предъявлен автомат.
- [ ] Предъявлены два представления (регулярка **и** ДКА) — это +1 балл.
- [ ] Таблица классов приложена: она же минимальность, она же оценка на НКА.
- [ ] Для регулярного языка построен синтаксический моноид — ещё +1 балл.
- [ ] Если регулярка вышла бы экспоненциальной, это сказано словами.
- [ ] Автомат прогнан против предиката (`disagreements`), а не «на глаз».
