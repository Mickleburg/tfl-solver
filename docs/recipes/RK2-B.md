# RK2-B — язык, заданный теоретико-множественным описанием

**Задача 2 каждого варианта РК2.** Дан язык записью вида

$$\{\, c^i a^n c^* b^k c^j \mid k = n \lor (i + j > 1\ \&\ i < j) \,\}$$

и спрашивают, где он лежит в иерархии. Вопрос почти всегда **двойной**:
регулярен ли, КС ли и — отдельно — **детерминирован ли**.

> Красная пометка на проверенной работе, где студент остановился
> на «язык КС»: **«детерминизм?»** Балл потерян не за ошибку,
> а за неотвеченный вопрос.

Оракулы: `tfl/lang.py`, `tfl/pump.py`, `tfl/pda.py`, `tfl/automata.py`.

---

## Шаг 1. Перевести описание в предикат и проверить перевод

Это единственное место, где ошибка стоит всей задачи, и автоматизировать
его нельзя: предикат пишется руками.

```python
from tfl.lang import from_predicate

def predicate(w: str) -> bool:
    ...

L = from_predicate(predicate, "abc", "язык из условия")
sorted(L.words(6))[:20]     # глазами: то ли это, что написано в условии
```

Обязательно выписать несколько слов **вручную** по условию и сверить
с `L.words`. Кванторы под чертой — источник большинства ошибок: `w₁` и `w₂`
в записи `{w₁ u uᴿ w₂ | …}` стоят под **существованием**, поэтому язык
часто оказывается куда шире, чем кажется.

Из-за этого же бывает наоборот: условие схлопывается. photo_162, `|w₀| < 3`
ограничивает `w₀` тремя вариантами, и всё описание сводится к «на позициях
`i+1` и `q ≥ 2i+3` стоит одна и та же буква» — а это **регулярно**.

## Шаг 2. Разложить дизъюнкцию

Условие почти всегда имеет вид `A ∨ B`, значит `L = L_A ∪ L_B`. Иногда одна
часть тривиальна, иногда классы у частей разные. Классы замкнуты
относительно объединения по-разному:

| Класс | ∪ | ∩ | дополнение | ∩ с регулярным | гомоморфизм |
|---|---|---|---|---|---|
| регулярные | да | да | да | да | да |
| КС | да | **нет** | **нет** | да | да |
| DCFL | **нет** | **нет** | **да** | да | **нет** |

Отсюда два рабочих приёма.

**`≠` разбирается на два неравенства.** Условие `n₁ ≠ n₂` стеком не считается,
а `n₁ < n₂` и `n₁ > n₂` считаются по отдельности, и объединение КС-языков —
КС (photo_141).

**Дополнение — вход в DCFL.** DCFL замкнут относительно дополнения, поэтому
чтобы доказать, что язык не DCFL, можно доказать это про его дополнение
(photo_123). Для КС так нельзя: КС относительно дополнения не замкнут.

## Шаг 3. Регулярность

Основной приём курса: пересечь с регулярным и различать префиксы.

```python
from tfl.lang import family, at_least_classes, table

L1 = L.restrict("a*ba*")                 # содержательный выбор — ваш
at_least_classes(L1, family(lambda i: "a"*i, 8), family(lambda j: "b"*j, 8))
print(table(L1, prefixes, suffixes).markdown())
```

`at_least_classes` возвращает **доказательство**: различили `n` префиксов —
значит классов не меньше `n`. Растущее по `n` семейство даёт бесконечность.
Таблицу из отчёта стоит приложить: в проверенных работах она встречается
чаще всего и всегда засчитывается.

Если язык оказался регулярным — предъявить ДКА и обосновать, почему памяти
хватает конечной. Формулировка из photo_163: «условие проверяется конечной
памятью, поэтому язык регулярен; а раз регулярен, то и DCFL».

## Шаг 4. Контекстная свобода

```python
from tfl.pump import noncf_by_pumping

noncf_by_pumping(L1, lambda p: "a"*p + "b"*p + "c"*p, upto=5)
```

Перебираются **все** разбиения. Это ровно то место, где теряют баллы чаще
всего: пять красных пометок из девяти — про непройденные разбиения
(«я разложу как `Q(Q(Q(S)Q)Q)Q` — и всё», «почему я не могу накачать `(ba)²`?»).

Если накачка не берёт, есть два более тонких приёма из работ на 5 баллов:

* **гомоморфизм в унарный алфавит.** Пересечь с регулярным, стереть лишние
  буквы гомоморфизмом (КС относительно него замкнут) и получить язык вида
  `{a^{m²}}`. Дальше работает следствие теоремы Париха из лекции 7:

  > Множества регулярных и КС-языков над однобуквенным алфавитом совпадают.

  Значит над одной буквой накачка для КС не нужна — хватает обычной
  таблицы Майхилла–Нероуда:

  ```python
  from tfl.lang import family, one_letter_noncf

  one_letter_noncf(unary, family(lambda i: "a"*i, 9), family(lambda j: "a"*j, 9))
  # да: классов не меньше 9; над однобуквенным алфавитом регулярные
  # и КС-языки совпадают, поэтому та же оценка запрещает и КС-свойство
  ```

  Так устроено доказательство из работы на 5 баллов (photo_176).

* **теорема Париха напрямую**: образ Париха КС-языка полулинеен,
  а `{4t² + 1}` — нет (photo_161). Проверки полулинейности в проекте нет
  и по предикату быть не может; практический путь — свести к однобуквенному
  случаю, как выше.

## Шаг 5. Детерминированность

Тот самый вопрос, который забывают.

**Если да** — предъявить ДМП-автомат и обосновать детерминизм:

```python
from tfl.pda import parse_pda

A = parse_pda(текст)
A.is_deterministic()
A.disagreements(L, max_len=9)      # обязательно: автомат против предиката
```

Красная пометка «`ab³` примет» стоит ровно там, где автомат не прогнали
против условия. Проверка — одна строка.

**Если нет** — лемма Ю (теорема S. Yu, лекция 9):

> Пусть `L` — DCFL. Тогда существует `p` такое, что для всех пар
> `w = xy ∈ L`, `w′ = xz ∈ L` с `|x| > p` и совпадающими первыми буквами
> `y` и `z` выполнено одно из двух:
> 1. существует накачка только префикса `x` в привычном смысле;
> 2. существует разбиение `x = x₁x₂x₃`, `y = y₁y₂y₃`, `z = z₁z₂z₃`
>    с `|x₂x₃| ≤ p`, `|x₂| > 0`, при котором для всех `i` **оба** слова
>    `x₁x₂ⁱx₃y₁y₂ⁱy₃` и `x₁x₂ⁱx₃z₁z₂ⁱz₃` остаются в `L`.

```python
from tfl.pump import nondcfl_by_pumping

def witness(p):
    n = p + 2
    return "a"*n + "b"*(n-1), "b", "b"*(n+1)     # (x, y, z)

nondcfl_by_pumping(L, witness, upto=3)
```

Ключевое: накачка идёт **синхронно** в префиксе и в обоих хвостах. Красная
пометка на работе: «можно качать `x` с `y` синхронно в одном слове» —
разбирать их по отдельности нельзя.

Пример из лекции: `L = {aⁿbⁿ} ∪ {aⁿb²ⁿ}`, `x = aⁿbⁿ⁻¹`, `y = b`,
`z = bⁿ⁺¹` при `n − 1 > p`.

**Против LL(k)** работает «метод неожиданного конца» (photo_123): предъявить
слово, на котором вход кончился, а стек непуст.

## Шаг 6. Язык не КС — тогда конъюнктивная грамматика (3 балла)

Разбалловка РК2 2023 (`corpus/issues/rk-2023-issues21-25.md`) устроена так,
что доказать «язык не КС» — это только 3 балла из девяти базовых. Ещё
3 балла отдельно платят за **построение конъюнктивной грамматики общего
вида** (либо за обоснование, что линейной не существует), и столько же —
за MFA или ref-слово.

Определение курса (лекция 11, слайд 10):

> Конъюнктивная грамматика `G` — грамматика, правила которой имеют вид
> `Aᵢ → Φ₁ & ⋯ & Φₙ`, где `Aᵢ` — нетерминал; `Φⱼ` — строки в смешанном
> алфавите терминалов и нетерминалов.

**Конъюнкция — это одно и то же слово, разобранное дважды**, а не разные
его части. Отсюда и сила класса: `S → A & B` требует от слова сразу двух
свойств.

```python
from tfl.conj import parse_conjunctive

G = parse_conjunctive("""
    S -> D & T | A
    D -> P a M
    P -> a P a | b
    M -> a M | G
    G -> ε | b Z
    Z -> a Z | b Z | ε
    T -> a T | b S
    A -> a A | ε
""")
G.agrees_with(increasing, max_len=9)     # сверка с предикатом условия
G.is_linear()                            # False: в конъюнкте D два нетерминала
```

Это разобранный билет 23 экзамена 2024: язык
`{a^i₁ b a^i₂ b … b a^iⁿ | k > 0 ⇒ i_j < i_{j+k}}`, то есть длины блоков
строго возрастают. Грамматика сверена с предикатом на всех словах
до длины 9.

**Приём, которым она построена**, переносится на весь класс «цепочка
попарных условий»:

* один конъюнкт (`D`) отвечает за **первую пару** блоков — это обычное
  КС-условие `i₁ < i₂`, здесь оно собрано из `P → aPa | b`;
* второй конъюнкт (`T → aT | bS`) говорит, что **хвост после первого `b`
  сам лежит в языке**;
* конъюнкция сшивает их на одном и том же слове, и рекурсия по `S`
  протягивает условие вдоль всей цепочки.

КС-грамматикой так не выйдет: одно правило не может одновременно
сравнивать первую пару и требовать рекурсию от суффикса.

### Проверка, что конъюнктивная грамматика вообще нужна

Прежде чем её строить, стоит убедиться, что язык не КС — иначе за
конъюнктивную грамматику заплатят, а за более слабое утверждение нет.
Для языка возрастающих блоков:

```python
three = L.restrict("a*ba*ba*")           # три блока — два сравнения сразу
noncf_by_pumping(three, lambda p: "a"*p + "b" + "a"*(p+1) + "b" + "a"*(p+2))
#   «не выяснено»: свидетель отбивает накачку при всех p ≤ 4
```

Исход «не выяснено» здесь рабочий: он подтверждает, что семейство выбрано
верно, и остаётся написать шаг при произвольном `p`.

### Линейные конъюнктивные грамматики и автоматы Треллиса

> Языки, распознаваемые такими автоматами, — это в точности линейные
> конъюнктивные языки. (лекция 11, слайд 14)

Линейность значит «не больше одного нетерминала в каждом конъюнкте»
(`ConjunctiveGrammar.is_linear`). За линейную грамматику **или** автомат
Треллиса на РК2 платят те же 3 балла в случае «КС, но не детерминированный».

Автомат Треллиса считает треугольник: нижний ряд — состояния отдельных
букв, каждая следующая ячейка — из двух соседних снизу. Перевод в грамматику
берётся прямо из лекции:

> `S → A_final`; `A_init(a) → a, a ∈ Σ`; `A_δ(q1,q2) → A_q1 c & b A_q2, ∀b, c ∈ Σ`

```python
from tfl.conj import Trellis

machine.accepts("bab")                  # треугольник
machine.agrees_with_grammar(max_len=7)  # сверка конструкции с автоматом
```

Читается конструкция так: слово с вершиной `δ(q1,q2)` — это слово,
у которого начало без последней буквы имеет вершину `q1`, а конец
без первой буквы имеет вершину `q2`. Обе половины описывают **одно и то же**
слово, поэтому и нужна конъюнкция.

Пустое слово автомат Треллиса не принимает никогда: у него нет нижнего ряда.

## Шаг 7. MFA и ref-слова — ещё 3 балла

Разбалловка платит за MFA и за конъюнктивную грамматику **отдельно**:
это два независимых представления, и взять можно оба.

> `k−MFA A` имеет функцию перехода из `Q × Σ ∪ {ε} ∪ {1,…,k}`
> в подмножество `Q × ⟨o, c, ⋄⟩ᵏ` (лекция 12, слайд 7)

Ячейка памяти хранит подслово, прочитанное с ленты, и его можно
потребовать снова — это формализм для регулярок с обратными ссылками,
то есть тот же предмет, что ЛР4, только со стороны распознавателя.

**Тонкость, которую лекция выделяет отдельно и на которой ошибаются:**

> мы сначала открываем (или закрываем) память, а уже потом читаем
> с ленты и пишем в открытые ячейки

Отсюда три следствия:

* открытие закрытой ячейки её **обнуляет** (`u' = v`, а не `u·v`);
* дописывание идёт, только если ячейка была открыта и осталась открытой;
* закрытая ячейка содержимое сохраняет.

```python
from tfl.mfa import parse_mfa

machine = parse_mfa("""
    q0 2 q1 o ⋄
    q1 1 q2 c o
    q2 a q3 ⋄ ⋄
    q3 2 q1 o c
""", start="q0", accepting="q3", cells=2, alphabet="a")

machine.words(16)          # ['a', 'aaaa', 'aaaaaaaaa', 'aaaaaaaaaaaaaaaa']
machine.is_deterministic() # True
machine.memory_after("aaaaaaaaa")   # ⟨aa, c⟩ ⟨aaa, o⟩
```

Это автомат лекции для `{aⁿ²}` по выражению `([1x2]1[2x1a]2)+`. Память
при `k`-м посещении `q3` равна `⟨⟨aᵏ⁻¹,c⟩,⟨aᵏ,o⟩⟩` — ровно как в лекции,
и это удобная проверка, что автомат выписан верно.

**Ref-слова** (Schmid, 2014) — та же память, записанная линейно:

```python
from tfl.mfa import parse_ref_word

ref = parse_ref_word("[1a[2b]1x1]2x2")
ref.expand()      # 'ababbab'
ref.values()      # {1: 'ab', 2: 'bab'}
```

Разные скобочные блоки разрешается **путать**: `[1` закрывается внутри
блока `[2`. Этим ref-слова и отличаются от обычной скобочной записи.

### Сторона «не существует»

Столько же баллов платят за обоснование, что детерминированного
или ациклического MFA не существует. Механизировано одно направление —
лемма о накачке для CSY-языков (слайд 5):

> `∃N ∀ω ∈ L (|ω| > N ⇒ ω = x₀yx₁y…yx_m & |x₀y| < N & |y| > 0
> & ∀i > 0 (x₀yⁱx₁yⁱ…yⁱx_m ∈ L))`

Накачивается **одно и то же** `y` сразу во всех выбранных вхождениях —
не один кусок, как в обычной лемме. И степень `0` в перебор не входит:
лемма говорит только про `i > 0`.

```python
from tfl.pump import noncsy_by_pumping

noncsy_by_pumping(anbn, lambda n: "a"*n + "b"*n, upto=5)
#   свидетель отбивает накачку при всех работающих N ≤ 5
```

Это классический пример лекции: `aⁿbⁿ` CSY-регуляркой не описывается.
Обратите внимание на «работающих»: при `N = 1` допустимых разбиений
не существует вовсе (`|y| > 0` и `|x₀y| < 1` несовместимы), и такое `N`
не говорит ни за, ни против.

Против DMFL работает **Jumping Lemma** (слайд 12), она не механизирована:

> `∀m ∃n, pₙ, vₙ`: `n ⩾ m`, `|vₙ| = n`, `vₙ` — подслово `pₙ`,
> `pₙvₙ` — префикс какого-то слова из `L`,
> и `∀u ∈ Σ⁺ (pₙu ∈ L ⇒ vₙ — префикс u)`.

Разбор лекции: `L = {aⁿwbⁿh(w)}` пересекается с `a*b+`, получается `aⁿbⁿ`;
`vₙ` обязано иметь вид `aⁿ`, тогда `pₙ = aⁿ⁺ᵏ`, слово `aⁿ⁺ᵏbⁿ⁺ᵏ` в языке,
но его суффикс `bⁿ⁺ᵏ` не начинается с `vₙ` — значит, язык не DMFL.

## Границы выводов

| Вывод оракула | Что он значит |
|---|---|
| различили `n` префиксов | **доказано**: классов не меньше `n` |
| свидетель не отбил накачку | **доказано**: свидетель негоден, берите другой |
| свидетель отбил накачку при `p ≤ N` | **ничего**: нужен произвольный `p` |
| `L ∩ R` не лежит в классе `K` | **доказано**: `L` не лежит в `K` |
| `L ∩ R` лежит в классе `K` | **ничего** про `L` — см. ниже |
| конъюнктивная грамматика совпала с предикатом до длины `N` | сильный довод, **не доказательство**: лемм о накачке для этого класса нет |
| автомат Треллиса совпал с построенной грамматикой | **доказано** для проверенных слов: конструкция лекции применена верно |
| MFA совпал с предикатом до длины `N` | сильный довод, не доказательство |
| накачка CSY дала `True` при работающих `N` | семейство выбрано верно; общий `N` пишет человек |
| накачка CSY дала пустой перебор | **ничего**: при таком `N` разбиений не существует |

> «А почему анализируете только пересечение? Оно может привести к переходу
> NCFL → DCFL в общем случае!» — красная пометка преподавателя.

Пересечение с регулярным — приём **односторонний**: им опровергают
принадлежность классу, но не доказывают её.
