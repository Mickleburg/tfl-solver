## Как решать: разобранные задачи каждой цены

### 1 балл. Минимальный ДКА (раздел A, 2021)

> Построить минимальный DFA, распознающий язык слов над `{a, b, c}` таких,
> что в них либо встречается хотя бы две буквы `c`, либо встречается
> хотя бы две одинаковые буквы подряд.

```python
from tfl.automata import dfa_of
from tfl.myhill import class_table

pattern = "(a|b|c)*c(a|b|c)*c(a|b|c)*|(a|b|c)*(aa|bb|cc)(a|b|c)*"
dfa = dfa_of(pattern, alphabet="abc").minimize()
len(dfa)                 # 7
print(class_table(dfa).to_markdown())
```

Семь состояний, и таблица классов сразу обосновывает минимальность.
Тот же язык стоит в разделе C задачей «построить синтаксический моноид»
на 1 балл: `syntactic_monoid(dfa)` даёт 15 элементов, моноид апериодичен.

### 1 балл. Регулярность языка со счётчиками (раздел B, 2021)

> Проверить, является ли регулярным язык
> `{w | w ≠ w₁aabw₂ & w ≠ w₁bbaw₂ & |w|_a = |w|_b}`

Условие `|w|_a = |w|_b` само по себе нерегулярно, поэтому первый порыв —
доказывать нерегулярность. Оракул говорит другое:

```python
from tfl.lang import from_predicate, from_regex, residual_growth

L = from_predicate(lambda w: "aab" not in w and "bba" not in w
                             and w.count("a") == w.count("b"), "ab")
residual_growth(L, max_prefix=8, suffix_len=8)
#   классов не меньше 3, кривая 1:2 2:3 3:3 3 3 3 3 — полка
L.words(8)          # ['', 'ab', 'ba', 'abab', 'baba', 'ababab', ...]
L.disagreements(from_regex("(ab)*|(ba)*", "ab"), 11)      # []
```

Язык — это `(ab)* ∪ (ba)*`, и он регулярен. Запреты `aab` и `bba`
заставляют буквы строго чередоваться, а равенство счётчиков добивает
чётность. Ответ на 1 балл — одна регулярка и объяснение в две строки.

**Мораль общая:** запрещённые подслова часто превращают нерегулярное
условие на счётчики в регулярный язык. Считайте кривую роста, прежде
чем строить накачку.

### 2 балла. Пополнение по Кнуту–Бендиксу (раздел F. модели, 2021)

> Произвести пополнение по Кнуту–Бендиксу SRS `gf → ff`; `fg → f`.

```python
from tfl.srs import parse_srs

srs = parse_srs("gf -> ff\nfg -> f")
srs.terminates().value            # True
srs.locally_confluent().value     # False — пара «fgf» не сходится
system, verdict = srs.complete(srs.find_shortlex_order())
print(system)     # fff → ff;  fg → f;  gf → ff
verdict.value     # True — все критические пары сходятся
```

Пополнение добавляет одно правило `fff → ff`. Критическая пара, из-за
которой оно понадобилось, — слово `fgf`: по `fg → f` получается `ff`,
по `gf → ff` получается `fff`.

### 3 балла. Когда пополнять нечего (раздел F. модели, 2021)

> Произвести пополнение по Кнуту–Бендиксу SRS `ba → ab`; `ab → bb`.

```python
srs = parse_srs("ba -> ab\nab -> bb")
srs.terminates().value            # True
srs.locally_confluent().value     # True — обе критические пары сходятся
```

Система уже сходящаяся: завершима и локально конфлюэнтна, а по лемме
Ньюмана этого достаточно. Ответ — «пополнять нечего», с предъявлением
обеих критических пар (`abb`/`bbb` и `bba`/`aab`) и их сведения.
Написать «пополнил» и выдать ту же систему — потеря балла.

### 5 баллов. Где оракул не справляется (раздел F, 2023 и 2025)

> Исследовать на завершаемость следующую SRS: `fg → gff`, `fh → hg`.

```python
parse_srs("fg -> gff\nfh -> hg").terminates()
#   None — ни петли, ни армейского порядка, ни линейной интерпретации
```

Расширенный поиск (наклоны до 5, сдвиги до 12, восемь миллионов
кандидатов) тоже ничего не даёт. Это честное «не выяснено»: нужен
более сильный порядок — рекурсивный по путям или матричная интерпретация
через SMT. Задача не зря стоит 5 баллов.

## Префиксные грамматики (раздел C, 2 и 4 балла)

Определение — лекция 4 курса 2022, слайд 31, дословно:

> Дана SRS `S` с правилами двух видов: `aᵢ → b₁…bₙ` и `aᵢ → ε`. Разрешим
> применять правила только к первым буквам слова. Пара `⟨S, w₀⟩`
> определяет алфавитную префиксную грамматику.
> **Утверждение.** Язык `L⟨S, w₀⟩` регулярен.

```python
from tfl.prefix import parse_prefix_grammar

apg = parse_prefix_grammar("a -> bb\nb -> a\nb -> ε", start="ab")
sorted(apg.collapsing())              # ['a', 'b']
apg.to_cfg()                          # линейная грамматика по лекции
apg.agrees_with_rewriting(max_len=7)  # сверка с прямым переписыванием
```

`to_cfg` — это конструкция из лекции, а `reachable` — прямое переписывание
первой буквы; написаны они независимо, и `agrees_with_rewriting` их
сверяет. Совпадение на всех словах до заданной длины и есть проверка
конструкции.

Ключевая деталь конструкции: фронт переписывания доходит до первой буквы,
которая **не коллапсирует**, и дальше не идёт никогда. Всё, что правее,
навсегда остаётся терминалами — отсюда линейность грамматики, а из неё
регулярность языка.

Префиксная грамматика нужна не только в «Аптеке»: это второе независимое
представление языка на задаче 2 РК1 (+2 балла), и на ней же стоит
следствие теоремы Турчина из лекции 6.

## Чего у нас нет

* **TRS с переменными** — термовые системы переписывания
  (`f(x, g(y)) → f(g(x), y)`, `w(w(w(s,X),Y),Z) → …`). Раздел «F. КЗ-языки»
  и часть банка вопросов. `tfl/srs.py` работает со строками.
* **Проблема соответствия Поста** — 4 балла в 2022, встречается и на экзамене.
* **Оценки уровня неразрешимости** («дать верхнюю оценку уровню
  неразрешимости задачи проверки языка на регулярность»).
* Задачи «на Тайное Знание» вроде переводчика из алгорифмов Маркова
  в рефал — вне области проекта, всё делаем на Python.

## Чего не делать

* Не браться за 5-балльную, не сняв 1- и 2-балльные: цена размечена
  по сложности, и она честная.
* Не доказывать нерегулярность, пока не посчитана кривая роста:
  запрещённые подслова регулярно превращают счётчики в чередование.
* Не выдавать исходную систему за пополненную: если пополнять нечего,
  так и надо написать, предъявив критические пары.
* Не переносить решение с TRS на SRS: у нас нет переменных, и это
  не мелочь, а другой класс задач.
