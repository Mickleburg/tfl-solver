## Карта понятий

1. Общая префиксная грамматика — пара `G=(W,R)`, где `W⊆A*` — базисные
   слова, а `R⊆A*×A*` — правила замены произвольного префикса. Из `u→v`
   следует `uz⇒vz` для любого суффикса `z`.
2. Для полугруппы `S` с присоединённой единицей `S¹` отношения Грина задаются
   главными идеалами:
   `a R b ⇔ aS¹=bS¹`, `a L b ⇔ S¹a=S¹b`,
   `a J b ⇔ S¹aS¹=S¹bS¹`, `H=L∩R`, `D=L∘R=R∘L`.
3. Всегда `D⊆J`; в конечной полугруппе `D=J`. Egg-box diagram одной
   `D`-классы располагает `R`-классы по строкам, `L`-классы по столбцам, а
   `H`-классы по ячейкам.
4. Лемма Грина о сдвигах даёт взаимно обратные биекции между соответствующими
   `L`-классами при `R`-эквивалентности и, двойственно, между `R`-классами при
   `L`-эквивалентности. Эти биекции сохраняют разбиение на `H`-классы.
5. Для `H`-класса эквивалентны наличие идемпотента, наличие произведения двух
   его элементов внутри класса, пересечение `H²` с `H` и свойство быть
   подгруппой. Такой класс является максимальной подгруппой полугруппы.
6. Лемма Ардена для уравнения `X=AX∪B` утверждает, что `A*B` всегда является
   решением, а при `ε∉A` это решение единственно.
7. Конечная система линейных регулярных уравнений решается исключением
   неизвестных: выделить самоссылку, применить лемму Ардена, подставить
   выражение в остальные уравнения и повторить.
8. Языки путей из состояний конечной системы переходов удовлетворяют такой
   системе уравнений. Это даёт конструктивный переход от конечного автомата к
   регулярному выражению.
9. Левая производная языка по слову `u` — остаточный язык
   `u⁻¹L={w | uw∈L}`. Автомат Брзозовского берёт производные языками состояний;
   он конечен ровно для регулярного языка и сразу минимален.
10. Алгебра Клини обобщает регулярные языки: сложение идемпотентно, естественный
    порядок задаётся `a≤b ⇔ a+b=b`, а звезда удовлетворяет аксиомам итерации.
    Полнота Козена связывает равенство выражений во всех алгебрах Клини с
    равенством соответствующих регулярных языков.

## Две разные префиксные грамматики в коде

`tfl.prefix.GeneralPrefixGrammar` соответствует определению этой лекции:
левая часть правила может быть любым словом, и заменяется весь совпавший
префикс. Именно этот класс используется в конструкции по правому графу ДКА.

`tfl.prefix.PrefixGrammar` — более узкий исторический объект, где правило
переписывает ровно первую букву. Он нужен старым задачам про алфавитные
префиксные грамматики. Смешивать эти два определения нельзя.

## Отношения Грина: как не перепутать стороны

- `R` определяется правым идеалом `aS¹`, потому что к `a` домножают справа.
- `L` определяется левым идеалом `S¹a`, потому что к `a` домножают слева.
- `H` требует одновременно `L`- и `R`-эквивалентности.
- Равенство `D=J` разрешено использовать для конечной полугруппы; в общем
  случае из лекции следует только включение `D⊆J`.

Таблица конечной полугруппы позволяет вычислить все главные идеалы полным
перебором, поэтому конкретная задача на классы Грина механически разрешима.
Отдельный публичный API добавляется при появлении реального задания, а не ради
формального расширения библиотеки.

## Лемма Ардена и системы уравнений

Условие `ε∉A` отвечает именно за единственность. Без него `A*B` остаётся
решением, но могут существовать и другие. Поэтому в решении нельзя просто
написать `X=A*B`, не проверив наличие пустого слова в коэффициенте при `X`.

При исключении нескольких переменных после подстановки сохраняется тот же вид
системы. Это аналог исключения Гаусса, но вместо деления используется лемма
Ардена. Промежуточные выражения могут быстро расти; их разрешено упрощать
только тождествами регулярных языков.

## Производные Брзозовского и ACI-нормализация

В проекте это уже реализовано двумя связанными слоями:

- `tfl.regex.Node.derivative` вычисляет производную выражения;
- `tfl.automata.brzozowski_dfa` строит ДКА по классам производных;
- `tfl.regex.alt` нормализует объединение по ассоциативности,
  коммутативности и идемпотентности, а также удаляет `∅`.

Без факторизации хотя бы по ACI синтаксически различных производных может
возникать бесконечно много, хотя различных языков-остатков у регулярного языка
конечное число. Реализация дополнительно применяет безопасные тождества для
конкатенации и звезды. Эквивалентность результата независимо сверяется с
построением Томпсона и минимизацией ДКА.

На слайдах знак `+` имеет два значения, которые определяются контекстом:
алгебраическое сложение означает объединение, а верхний индекс `r⁺` —
положительную итерацию `rr*`. В конкретных регулярных выражениях проект
использует `|` для альтернативы, чтобы избежать этой неоднозначности.

## Что проверено исполнением

- в текстовом зеркале ровно 20 страниц и присутствуют все ключевые заголовки;
- общая префиксная грамматика и конструкция по правому графу уже закреплены в
  `tests/test_prefix.py`;
- построение ДКА по производным сверяется с независимым построением Томпсона
  на всех архивных вариантах регулярных выражений в `tests/test_core.py`;
- применение леммы Ардена к рекурсивному примеру отдельно проверяется
  вычислением наименьшей неподвижной точки в `tests/test_issues.py`.

Конечные тесты проверяют реализации и конкретные примеры. Общие утверждения о
единственности решения, минимальности автомата Брзозовского и структуре
`H`-классов опираются на теоремы, сформулированные выше.
