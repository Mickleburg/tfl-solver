Источник — [официальный репозиторий курса](https://github.com/TonitaN/FormalLanguageTheory),

атрибуция и перечень изменений находятся в `THIRD_PARTY_NOTICES.md`.

Это не ошибка извлечения: отсутствующий пятнадцатый слайд про отношения Грина
был исключён из опубликованной версии. Все 14 страниц проверены по рендерам.

## Карта понятий

1. **Автомат Мили** задан пятёркой `(Q, Σ, Γ, δ, λ)` без начального
   состояния. В таком виде определено поведение из каждого состояния; чтобы
   получить единственное преобразование входного слова в выходное, отдельно
   выбирают начальное состояние. `tfl/mealy.py` хранит его явно.
2. **Действие группы** удовлетворяет `e·x=x` и `(gh)·x=g·(h·x)`.
3. В **правом графе Кэли** ребро `g -s-> gs`; в левом — `g -s-> sg`.
   Сторону умножения нельзя менять внутри решения.
4. Для полугруппы слова над образующими имеют положительную длину. Поэтому
   копредставление полугруппы задаёт `A⁺/≡`, а обход из пустого слова строит
   моноид `A*/≡` с внешне присоединённой единицей. Для подсчёта элементов
   полугруппы эту дополнительную вершину надо исключить.
5. Слово `w` действует на состояниях ДКА преобразованием
   `T_w(q)=δ(q,w)`. При обычной композиции функций
   `T_{uv}=T_v∘T_u`: сначала читается `u`, затем `v`.
6. Левая, правая и двусторонняя конгруэнции различаются стороной, на которой
   разрешено домножение. Это различие существенно для двух следующих
   пунктов.
7. Синтаксическая конгруэнция
   `u ≡ₛ v ⇔ ∀x,y: xuy∈L ⇔ xvy∈L` двусторонняя, поэтому классы образуют
   **синтаксический моноид**.
8. Отношение Майхилла–Нероуда
   `u ≡ᵣ v ⇔ ∀z: uz∈L ⇔ vz∈L` является правой конгруэнцией. Его классы —
   состояния минимального полного ДКА.
9. Общая префиксная грамматика — пара `G=(W,R)`, где `W⊆A*`,
   `R⊆A*×A*`, а правило применяется только в начале:
   `u→v` даёт `uz⇒vz`.

## Существенное уточнение к слайду о Майхилле–Нероде

Фактор `Σ*/≡ᵣ` для правой конгруэнции в общем случае является множеством
с правым действием букв, то есть автоматом, но не фактор-моноидом.
Произведение классов `[u][v]=[uv]` требует двусторонней конгруэнции: из
`v≡ᵣv'` нельзя в общем случае вывести `uv≡ᵣuv'`.

Поэтому корректная формулировка теоремы такова:

- `L` регулярен тогда и только тогда, когда правое отношение
  Майхилла–Нероуда имеет конечный индекс;
- число его классов равно числу состояний минимального полного ДКА;
- моноид получается после факторизации по **синтаксической двусторонней**
  конгруэнции со слайда перед ним.

## Префиксная грамматика из правого графа Кэли

Пусть дан достижимый ДКА `A=(Q,Σ,δ,q₀,F)`. Для каждого состояния `q`
выберем слово-представитель `r_q`, ведущее из `q₀` в `q`; удобно брать
кратчайшее слово из обхода в ширину.

Строим конечную префиксную грамматику:

```text
W = { r_f | f ∈ F }
R = { r_p → r_q a | в графе есть ребро q -a→ p }.
```

Тождественные правила можно удалить. Ориентация намеренно обратна ребру.

**Корректность.** Обе части правила приводят начальное состояние в `p`:
`δ(q₀,r_p)=p=δ(q₀,r_q a)`. Поэтому для любого суффикса `z` слова
`r_pz` и `r_qaz` либо оба принимаются, либо оба отвергаются. Значит из
финального базисного слова нельзя породить слово вне языка.

**Полнота.** Пусть `w=a₁…aₙ∈L`, а `q_i=δ(q₀,a₁…a_i)`. Из базиса
`r_{q_n}` последовательно применяем правила для рёбер в обратном порядке:

```text
r_qn ⇒ r_q(n-1) a_n ⇒ … ⇒ r_q0 a₁…aₙ = w,
```

поскольку `r_q0=ε`. Следовательно, грамматика порождает в точности `L`.
Та же конструкция работает для правого графа Кэли конечного моноида: финально
помечаются те действия `m`, для которых состояние `q₀·m` финально.

Конструкция реализована как `tfl.prefix.dfa_to_prefix_grammar`; прямое
префиксное переписывание и распознавание ДКА сверяются независимо методом
`GeneralPrefixGrammar.agrees_with_dfa`.

## Несколько лексических доменов

Для доменов `T₁,…,T_k` сначала строится один конечный правый граф, вершина
которого окрашена множеством доменов, принимающих соответствующий префикс.
Если исходно даны разные ДКА, таким графом служит их прямое произведение.

Для каждого домена берётся свой базис

```text
W_i = { r_q | вершина q окрашена цветом T_i }.
```

Обращённые рёбра `r_p→r_q a`, помеченные `(T_i,T_i)`, уже дают отдельную
префиксную грамматику каждого домена. Более общая метка `(T_i,T_j)` у правила
`u→v` корректна ровно тогда, когда включены правые остаточные языки:

```text
∀z: uz ∈ T_i  ⇒  vz ∈ T_j.
```

На конечном раскрашенном графе это разрешимая проверка. Одновременно обходим
пары вершин `(δ(q₀,u z), δ(q₀,v z))`. Если достижима пара, где первая вершина
имеет цвет `T_i`, а вторая не имеет цвета `T_j`, накопленный `z` — кратчайший
контрпример. Если таких пар нет, правило доказанно корректно для всех
суффиксов. Для равенства доменов проверяются оба включения.

Эта проверка реализована как `tfl.prefix.check_labelled_rule` и возвращает
суффикс-свидетель при неверной метке.

## Что проверено исполнением

- текстовое зеркало содержит ровно 14 страниц и все ключевые заголовки;
- конструкция по правому графу сверена с независимым запуском ДКА на всех
  словах тестового алфавита до фиксированной длины;
- проверка размеченного правила протестирована и на истинном включении
  остаточных языков, и на случае с кратчайшим контрпримером.

Конечная сверка на коротких словах подтверждает реализацию, а общую
корректность конструкции дают два доказательства выше.
