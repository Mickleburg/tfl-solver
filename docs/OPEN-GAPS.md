## P0 — довести агента как систему

### Актуальный курс 2026

Формат контроля записан в `docs/COURSE-2026.md`, runtime умеет отдельно
маршрутизировать РК, лабораторные по содержанию и аудит ИИ-решения. Для
полноценной подготовки ещё нужны внешние материалы, которых в корпусе нет:

- условия всех четырёх лабораторных и точные критерии по 7 баллов;
- номер лабораторной с защитой, цена ЛР4 и точное правило замены после
  неудачной защиты;
- полная заранее известная база карточек РК и правила таймера;
- примеры части 1 экзамена и «нейрослопа» части 2 с критериями разбора;
- регрессионный timed-eval: точность ответа, время до краткого ответа и
  качество устной защиты.

Big Pharma исключена из актуального плана. Код, рецепт и старые задачи
`PHARMA` остаются историческими регрессиями и не должны влиять на стратегию
набора баллов 2026.

### Сквозной eval LLM-цикла

Holdout v1 из семи задач 2021–2025, JSON Schema, runners Codex/Claude и scorer уже
лежат в `evals/agent_holdout/` и `tfl/agent_eval.py`. Осталось:

- снять оставшиеся пять случаев полного baseline v1 и разобрать провалы;
- проверить эффективность лимита на полном baseline: первый smoke до него
  потребовал 15 команд/197,57 с/415365 входных токенов, второй с лимитом —
  9 команд/227,53 с/294894 токена; одной разнотипной пары недостаточно для
  вывода о wall-clock и стоимости;
- повторить Claude smoke после появления API-ключа или разрешения Claude Code
  в организации: adapter и event-stream parser готовы, но текущий live-запуск
  останавливается с 403 `oauth_org_not_allowed` до первого tool call;
- провести ручную предметную проверку финальных доказательств: текущий scorer
  надёжно ловит маршрут, пустые свидетельства и завышенный статус конечного
  перебора, но смысловые якоря не заменяют математического рецензента;
- после публикации создать v2 со слепыми задачами 2026 года.

## P1 — предметные пробелы

### ЛР1: завершимость SRS

Не выяснены варианты 10, 16, 17, 18, 21, 22, 24, 26, 27. Для вариантов 11 и 15
есть только полные проверки на фиксированных длинах. Следующие направления:

- арктические интерпретации с отрицательными элементами и парами зависимостей;
- RFC match bounds и quasi-deterministic completion;
- SMT-поиск на больших доменах;
- явный анализ квадратичных length-preserving выводов.

### Минимальная эквивалентная SRS

Нет полного метода для конечного множества нормальных форм. Кнут–Бендикс
расходится на варианте 20, а компактный результат из студенческой работы пока
не воспроизведён независимо. Текущая стабилизация числа классов остаётся
эвристикой.

### ЛР4

- Реализовать точную принадлежность для строковых backreference; текущий
  скелет расширенной регулярки теряет часть lookaround-семантики.
- Добавить полноценный сценарий нечётных вариантов ЛР4 с атрибутными
  грамматиками поверх существующего `tfl/attr.py`.

### Шаблонные системы переписывания

Нужны символьная унификация и решение простых словных уравнений. Без них
положительное доказательство локальной конфлюэнтности правил с переменными
остаётся ручным.

### Теория 2026

- Механизировать применение ping-pong lemma.
- Восстановить точное условие примера 1.78; в доступных материалах есть только
  ссылка на номер.
- После каждой лекции сверять новые определения с прежней нумерацией курса.

## Намеренные границы

Следующие ручные исходы сами по себе не являются дефектом агента:

- доказательство детерминированности языка или невозможности real-time PDA в
  общем случае;
- изобретение контрпримера к замыканию без ограниченного семейства кандидатов;
- общий тест семилинейности образа Париха по произвольному предикату;
- вывод общего утверждения из конечного перебора.

Для таких задач корректный результат — содержательный ручной план,
проверенные частные случаи и честный статус.
