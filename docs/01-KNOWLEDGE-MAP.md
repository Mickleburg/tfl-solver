## 4. Слой D — `corpus/` (текстовое зеркало)

```
tools/extract_corpus.py     # переизвлечение; --render FILE.pdf N M -> PNG
corpus/INDEX.tsv            # kind(TEXT|SCAN) | страниц | символов | txt | pdf
corpus/txt/*.txt            # 117 файлов; разметка страниц «----- [page N] -----»
corpus/png/<stem>/pNN.png   # рендеры сканов (создаются по требованию)
```

**Грепать корпус, а не PDF:**

```powershell
rg "префикс-свойств" corpus/txt
Import-Csv -Delimiter "`t" corpus/INDEX.tsv | Where-Object kind -eq SCAN
py -3 tools/extract_corpus.py --render "references/course/TFL-IU9-claude/РК1/tfl_rk1_var_2.pdf" 1 5
```

### Три ловушки извлечения (вылечены в скрипте, но знать надо)

1. **CP1251-байты.** `pdftotext` на LaTeX-PDF курса отдаёт кириллицу однобайтовой
   CP1251 — получается `Âàðèàíò`. Лечится PyMuPDF плюс посимвольной перекодировкой.
2. **Шрифт без ToUnicode.** У `lab_tfl_2025_*.pdf` `pdftotext` молча выбрасывает
   всю кириллицу, оставляя одни формулы. PyMuPDF читает их корректно. Если в
   тексте задания зияют дыры — это оно.
3. **Сканы.** После дедупликации индекс содержит 4 файла без текстового слоя.
   Ещё 3 имеют ненадёжный OCR (`tfl_lec_sem`, `tfl_rk1_var_2_new`,
   `tfl_rk2_var_8`) и тоже требуют сверки по рендеру PNG.

## 5. Внешние верификаторы (из `references/teacher/FormalLanguageTheory/README.md`)

То, чем результат можно **проверить машинно**:

| Инструмент | Что проверяет |
|---|---|
| [Эквивалентность регулярок](https://bakkot.github.io/dfa-lib/regeq.html) | равенство языков двух регексов |
| [Grammophone](https://mdaines.github.io/grammophone/#/) | LL(1), LR(0/1), неоднозначность КС-грамматики |
| [LL(1)-разбор](https://www.cs.princeton.edu/courses/archive/spring20/cos320/LL1/), [LR(0)-разбор](https://www.cs.princeton.edu/courses/archive/spring20/cos320/LR0/) | пошаговые таблицы разбора |
| [Минимизатор ДКА](https://aswaddev.github.io/dfa-minimizer/) | минимальность автомата |
| [CYK онлайн](https://www.xarg.org/tools/cyk-algorithm/) | принадлежность слова КС-языку |
| [Тестировщик КС-грамматик (Stanford)](https://web.stanford.edu/class/archive/cs/cs103/cs103.1156/tools/cfg/) | грамматику против набора слов |
| [Решатель регулярных уравнений](https://smegdm.github.io/tfl/lab2/regex_system_solver/index.html) | системы уравнений Ардена |
| [regextocfg.ru](https://regextocfg.ru) | AST расширенного регекса (ЛР4). На КС-грамматику **не смотреть** — преподаватель прямо предупреждает, что она неадекватна |
| Z3 / SMT-LIB | завершаемость TRS через линейные интерпретации |

Плюс студенческие инструменты из README: `Chipollino` (конвертер автоматов и
регулярок с пошаговым выводом в LaTeX), `converter_team_project`, ГНФ-конвертер,
построитель трансформационного моноида, генератор случайных грамматик,
`regex_fuzzing`.
