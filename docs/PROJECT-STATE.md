# Актуальное состояние tfl-solver

Дата среза: **2026-09-13**. Это единственный документ с текущими числовыми
показателями. Хронология разработки сохранена в `docs/archive/`.

Статус: **версия 1.0, базовая разработка завершена, режим сопровождения**.
Новая архитектурная работа не планируется без обнаруженного дефекта или явного
запроса. При публикации условий ЛР-2026 приоритет немедленно переходит от
разработки агента к выполнению соответствующей лабораторной.

## Цель

Переносимый учебный помощник быстро объясняет любую теорию ТФЯ, принимает
полное условие задачи текстом или фотографией и выполняет цикл:

```text
условие → классификация → рецепт → формализация → гипотеза ↔ Python-оракул
        → доказательство → отчёт с явной границей проверенного
```

Результатом служит либо оформленное и проверенное решение, либо содержательный
частичный результат: доказанные факты, опровергнутые гипотезы и оставшиеся
обязательства.

Для лабораторной результатом становится отдельный автономный проект: только
Python 3.11+ и стандартная библиотека, без импорта `tfl`, сети и внешних
пакетов. В него входят полное условие, реализация, `unittest`, README, описание
корректности и фактическое раскрытие использования ИИ. На РК и экзамене агент
не используется; он заранее готовит к самостоятельному решению и объяснению.

Форма контроля 2026 зафиксирована в `docs/COURSE-2026.md`: четыре
лабораторные с раскрытием использования ИИ, РК по известной базе под таймером,
двухчастный экзамен с аудитом ИИ-решения и собеседование для оценки 5. Big
Pharma в текущем курсе отсутствует.

## Готово

- Канонический repo-skill для Codex: `.agents/skills/tfl-solver/SKILL.md`.
- Адаптер Claude Code: `.claude/skills/tfl/SKILL.md`.
- Устанавливаемый из GitHub wheel 1.0 включает skill, рецепты, документацию,
  корпус, eval и Python-оракулы; чистая пакетная установка проверена отдельно
  от исходного дерева.
- Переносимая CLI: `tfl` / `py -3 -m tfl` / `tfl-agent` с командами `setup`,
  `root`, `doctor`, `intake`, `lab`, `eval`, `holdout`.
- `tfl setup` безопасно ставит пользовательские точки входа: Claude Code
  `/tfl`, Codex `$tfl-solver` и `/prompts:tfl`; чужие файлы без `--force` не
  перезаписываются.
- Стандарт автономной лабораторной и `lab init/check`: безопасная заготовка,
  аудит структуры, заглушек, импортов/деклараций зависимостей и запуск тестов
  только стандартной библиотекой.
- Быстрый режим теоретического помощника: прямой ответ и минимальный пример
  без обязательного запуска диагностики, intake и поиска по всему корпусу.
- 18 рецептов: LAB-1…5, RK1-A…C, RK2-A…C, EXAM-1…3, EXAM-ERROR, MAT, CODE,
  PHARMA. Последние исторические `LAB-5`/`PHARMA` не считаются формой 2026.
- Python-оракулы для регулярных языков и автоматов, SRS/TRS, CFG/PDA,
  атрибутных грамматик, AFA и расширенных регулярок, GLR/GLL, L*/NL*,
  моноидов, PCP, копредставлений, автоматов Мили/Мура и сетей
  Мак-Каллока–Питтса.
- Входной индекс задач 2021–2025 и поиск похожих условий.
- Все локальные первоисточники собраны под `references/` по уровню доверия.
- Сценарий editable-установки, `doctor` и `intake` проверен в чистом клоне без
  локальных `references/` и при запуске из другой рабочей директории.
- Заморожен holdout v1 из 7 задач 2021–2025; CLI умеет запускать Codex в
  read-only режиме или Claude Code с узким allowlist инструментов и оценивать
  маршрут, формализацию, реальные команды оракулов, статусы и итоговый ответ.

## Граница версии 1.0

Библиотека оракулов, предметные рецепты, автономная граница проектов ЛР,
пакетная переносимость и harness сквозной оценки работоспособны. Это завершённая
база помощника, а не обещание разрешить любой неразрешимый класс задач.

Полный baseline LLM-цикла, Claude smoke после снятия внешнего auth-блокера и
часть предметных исследований остаются полезными проверками, но не блокируют
обычное использование 1.0. Проверить неизвестные сейчас условия ЛР и слепые
задачи 2026 невозможно до их публикации. Эти пункты сохранены в
`docs/OPEN-GAPS.md` как наблюдаемая граница и очередь сопровождения, а не как
план непрерывной разработки.
