# Режимы решения и понятные человеку методы

Режим отвечает не за математическую силу оракула, а за способ выбора и
объяснения метода. Он ортогонален бюджету `quick / standard / research / lab`:
короткая задача может решаться в полном режиме, а большая — в тренировочном.

## Режим `training` — по умолчанию

Цель — научить пользователя повторить решение самостоятельно.

Порядок выбора метода:

1. найти до трёх похожих **проверенных** задач из уже пройденных семинаров;
2. выбрать самый близкий знакомый приём по признакам условия;
3. если аналог подходит лишь частично, явно назвать совпадающую и новую части;
4. только при отсутствии рабочего аналога перейти к общему рецепту класса;
5. проверить ключевой шаг оракулом, но объяснить доказательство без ссылки на
   авторитет программы.

Ответ строится так:

1. «Заметим, что …» — наблюдение;
2. «Это видно по признакам …» — буквальные фрагменты или свойства условия;
3. «Похоже на задачу …, где использовали …» — семинарский аналог без
   притворства, что задачи одинаковы;
4. малые приёмы до основной теоремы;
5. основной метод;
6. проверка, доказательство и границы.

Если метод ещё не был пройден, в `training` он не становится основным только
потому, что короче. Сначала используется доступный метод курса. Более сильный
метод можно указать отдельно как альтернативу.

## Режим `full`

Цель — найти наиболее сильное корректное решение, когда знакомых приёмов
недостаточно. Разрешены несколько формализаций, несколько рецептов, дорогие
оракулы и продвинутые теоремы.

Порядок:

1. всё равно проверить семинарские аналоги как дешёвые гипотезы;
2. составить портфель формализаций и отсеять нарушающие условие;
3. исследовать альтернативные методы из всего корпуса;
4. сравнить решения по доказательности, простоте объяснения и стоимости;
5. выдать самый понятный из полноценных методов, а не самый технически
   сложный.

Полный режим используется по просьбе пользователя, при новой предметной теме,
в исследовательской задаче и при разработке лабораторной. Он не разрешает
подменять доказательство конечным перебором.

## Малые приёмы

Глобальный класс (`SRS`, регулярность, грамматика) не заменяет описание
локальных шагов. Перед основной теоремой агент помечает реально использованные
приёмы из короткого словаря:

| Этап | Малые приёмы |
|---|---|
| чтение | выписать кванторы; расставить скобки; уточнить область значений; разделить дизъюнкцию на случаи |
| нормализация | переименовать символы; отделить переменные от конструкторов; проверить арности; зафиксировать ε и направление правил |
| разведка | разобрать минимальные примеры; проверить край слова; поискать симметрию; рассмотреть дополнение |
| гипотеза | подобрать инвариант; подобрать монотонную меру; построить семейство свидетелей; найти аналог |
| проверка | искать минимальный контрпример; проверить обе импликации; сравнить модель и ручной пример; проверить все ограничения |
| объяснение | дать бытовую аналогию; назвать признак выбора метода; отделить факт от интерпретации |

Новые названия добавляются только если они различают действия. Слабой модели
проще выбрать два-три точных тега, чем сочинять длинную скрытую цепочку
рассуждений. В ответе показывается педагогическое обоснование метода, а не
внутренние рассуждения модели.

## Правило выбора между несколькими решениями

Сравнивать лексикографически:

1. выполнены все требования условия;
2. есть доказательство или полный конечный алгоритм;
3. метод уже встречался в пройденных материалах;
4. меньше новых понятий;
5. короче проверяемая цепочка шагов;
6. ниже вычислительная стоимость.

Эта шкала не позволяет предпочесть знакомое, но неверное решение. Первые два
пункта всегда старше педагогической простоты.
