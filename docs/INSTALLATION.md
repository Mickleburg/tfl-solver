# Установка и перенос tfl-solver

Версия 1.0 устанавливается прямо из GitHub и приносит с собой Python-оракулы,
канонический skill, документацию, рецепты, текстовый корпус и eval-набор.
Локальные тяжёлые оригиналы из `references/` в пакет не входят; для обычного
решения достаточно версионируемого `corpus/`.

## Быстрая установка из GitHub

Нужны Python 3.11+, Git и хотя бы один установленный и авторизованный клиент:
Claude Code либо Codex. Сам `tfl-solver` не содержит модель и не подменяет
аккаунт выбранного клиента.

Windows PowerShell:

```powershell
py -3 -m pip install --user --upgrade "git+https://github.com/Mickleburg/tfl-solver.git"
py -3 -m tfl setup
py -3 -m tfl doctor
```

Linux/macOS:

```bash
python3 -m pip install --user --upgrade "git+https://github.com/Mickleburg/tfl-solver.git"
python3 -m tfl setup
python3 -m tfl doctor
```

`tfl setup` устанавливает только три маленьких пользовательских адаптера и не
перезаписывает чужой файл без `--force`:

- `~/.claude/skills/tfl/SKILL.md` — команда Claude Code `/tfl`;
- `~/.agents/skills/tfl-solver/SKILL.md` — глобальный skill Codex
  `$tfl-solver`;
- `~/.codex/prompts/tfl.md` — slash-prompt Codex `/prompts:tfl`.

После первой установки перезапусти открытую сессию Claude Code или Codex, чтобы
клиент перечитал список skills. Проверка без изменений:

```powershell
py -3 -m tfl setup --status
py -3 -m tfl root
```

Если каталог пользовательских scripts находится в `PATH`, короткие команды
`tfl setup`, `tfl doctor`, `tfl intake ...` эквивалентны форме
`py -3 -m tfl ...`. Старое имя `tfl-agent` сохранено для совместимости.

## Как вызывать агента

В Claude Code команда точная:

```text
/tfl Объясни разницу между детерминированным и однозначным КС-языком
/tfl Реши задачу из приложенного изображения и проверь ключевые гипотезы
/tfl Создай автономный проект для этой ЛР и подготовь описание с промптами
/tfl Найди первую ошибку в этом решении и предъяви контрпример
```

В Codex основной вызов навыка:

```text
$tfl-solver Реши задачу и объясни доказательство
```

Slash-prompt Codex имеет документированный префикс `prompts`:

```text
/prompts:tfl Проверь это решение
```

После ключевого слова не требуется строгая грамматика действий: передавай
полное условие обычным языком, текстовым файлом или изображением. Агент сам
выбирает режим — короткая теория, отдельная задача, лабораторная либо
тренировка/аудит — и затем использует подходящий предметный рецепт и оракулы.

## Обновление и клон для разработки

Обновление установленной версии повторяет две команды:

```powershell
py -3 -m pip install --user --upgrade "git+https://github.com/Mickleburg/tfl-solver.git"
py -3 -m tfl setup
```

Для редактирования материалов удобнее клон:

```powershell
git clone https://github.com/Mickleburg/tfl-solver.git
cd tfl-solver
py -3 -m pip install --user -e .
py -3 -m tfl setup
```

Глобальные адаптеры запоминают путь к текущей установке. После перемещения или
удаления editable-клона повтори `tfl setup` из действующей версии.

## Другие LLM-клиенты

Универсального стандарта slash-команд между продуктами нет. Для другого
Claude/GPT-совместимого агента передай ему репозиторий и укажи полностью
прочитать `.agents/skills/tfl-solver/SKILL.md`; все знания и алгоритмические
маршруты остаются переносимыми. В веб-интерфейсе без доступа к локальным
файлам можно загрузить нужный рецепт и исходное условие, но Python-оракулы
тогда придётся запускать отдельно.
