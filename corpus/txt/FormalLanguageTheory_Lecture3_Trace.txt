Схема доказательства
Пусть a R b, то есть существуют s, s′ ∈S1: as = b и bs′ = a.
1. Корректность отображения ρs:
x ∈La =⇒x = ua =⇒ρs(x) = xs = u(as) = ub ∈Lb.

Теорема Грина об H-классах
Пусть S  полугруппа, H  некоторый H-класс в S.
Теорема (Грин).
Следующие условия эквивалентны:
1. H содержит идемпотент (e2 = e ∈H);
2. существуют a, b ∈H такие, что ab ∈H;
3. H2 ∩H̸ = ∅;
4. H является подгруппой в S.
Если указанные условия выполнены, то H является максимальной подгруппой
полугруппы S.
9/20, Конспект лекции 3, 19.09.26

Схема доказательства
Доказывается цикл эквивалентностей (4) =⇒(1) =⇒(2) =⇒(3) =⇒(4):
• (1) =⇒(2): Если e2 = e ∈H, то полагаем a = b = e =⇒ab = e ∈H.
• (2) =⇒(4): Пусть a, b ∈H и ab ∈H.
1. Сдвиг ρb : x 7→xb переводит H в H биективно (по лемме Грина, так как b R ab).
2. Значит, существует единственный e ∈H такой, что ρb(e) = eb = b.
3. Аналогично через левый сдвиг λe получаем e2 = e (единица группы).
4. Биективность сдвигов внутри H гарантирует существование обратного x−1 ∈H
для всякого x ∈H.
• (4) =⇒(1) и (3) ⇐⇒(2) тривиальны.

Алгебра Клини
Определение.
Алгеброй Клини называется структура (K, +, ·, ∗, 0, 1), где:
• (K, +, ·, 0, 1)  идемпотентное полукольцо:
a + a = a,
a + 0 = a,
a · 0 = 0 · a = 0,
a · 1 = 1 · a = a.
• Естественный частичный порядок: a ≤b ⇐⇒a + b = b.
• Операция итерации (звезда Клини) ∗: K →K удовлетворяет аксиомам:
1 + aa∗≤a∗,
1 + a∗a ≤a∗,
b + ax ≤x =⇒a∗b ≤x,
b + xa ≤x =⇒ba∗≤x.

ACI-упрощение в алгоритме Брзозовски
Множество синтаксических производных может быть бесконечным без
факторизации выражений.
ACI-свойства операции объединения (+):
• Associativity (ассоциативность): (r1 + r2) + r3 = r1 + (r2 + r3);
• Commutativity (коммутативность): r1 + r2 = r2 + r1;
• Idempotence (идемпотентность): r + r = r.
Правило построения автомата:
1. Дополнительно используются свойства нуля и нейтрального элемента:
r + ∅= r,
r · ∅= ∅· r = ∅,
r · ε = ε · r = r.
2. Производные рассматриваются с точностью до ACI-эквивалентности:
[r1]ACI = [r2]ACI.
Теорема (Брзозовски). Для любого регулярного выражения r число
неизоморфных производных с точностью до ACI конечно.
