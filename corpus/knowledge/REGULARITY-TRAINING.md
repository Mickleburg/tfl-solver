# Регулярность: границы разрезов и арифметические свидетели

Проверенная предметная выжимка; исходные условия всегда имеют приоритет.
Примеры и общие ключи — `study/rk1-2026/trainer/EXTRA-TASKS.md` и
`EXTRA-KEYS.md`; регрессии — `tests/test_rk1_trainer.py`.

## Существование разбиения

У `{w₁w₂w₃ : …}` несколько возможных свидетелей. Чтобы принять слово,
достаточно одного; чтобы отвергнуть — нужно исключить все. Сначала проверить
крайние разрезы и непустоту. Пустые края не означают автоматически Σ*:
для `w₁=w₃ᴿ, |w₂|_a=|w₃|_b` они допускают лишь b*. Регулярное ограничение
a+b+a+ устраняет все зеркальные края с b, остальные дают равные крайние
длины a и нерегулярное семейство. Подробно R01.

Для `{uv : |u|_aa=|v|_b}` разность счётчиков при движении разреза идёт
от неположительного к неотрицательному значению шагами 0/1, поэтому L=Σ*.
Для `{uv : |u|_ba=|v|_ab}` возможен шаг 2 на средней a в bab; слово
`(baab)^n a(baab)^m` принимается ровно при n≠m, n,m≥1. Это нерегулярный
язык. Знаки на концах без ограничения шага ничего не доказывают.

## От структуры слова к различению

- Оставить один блок b или единственное ab, чтобы снять выбор разделителя.
- Для чётного палиндрома длины ≥4 оставить центральные aaaa,abba,baab,bbbb.
  Если внешние части свободны — это регулярное условие наличия подслова.
  Если сравниваются длины контекстов, ограничение остаётся: P04/G10.
- Для скрытых сумм показателей использовать gcd(x−k,k)=gcd(x,k).
  Достаточное условие невозможности для всех k вместе с положительной
  диагональю даёт различающие продолжения без полного описания языка: P01/P03.
- Треугольная таблица достаточна: x_i z_i∈L, x_j z_i∉L при j>i.
  Не требуется вычислять все остальные клетки.

## Унарные длины

Путь однобуквенного ДКА в конце периодичен. Поэтому растущие расстояния
между допустимыми показателями дают противоречие фиксированному периоду.
Другой признак: сколь угодно длинные сплошные принимаемые интервалы вместе
с неограниченными пропусками невозможны — длинный интервал замыкает путь
в цикл только допускающих состояний. Применять к объединению целиком,
а не выводить его нерегулярность из одной части.

Неотрицательные разности квадратов x²−y², x≥y, — ровно длины, не равные
2 mod 4. Запрет остатка — только необходимость. Достаточность дают
2r+1=(r+1)²−r² и 4r=(r+1)²−(r−1)² при r≥1, ноль отдельно.
Получается `(aaaa)*(ε|a|aaa)`, а не нерегулярный язык «из-за квадратов».

## Дополнение и однозначность

В дополнении языка с существованием разделителей нужно отрицать все
допустимые выборы. Пара выбранных b не обязана быть соседней. Иногда удобно
сначала пометить каждую b остатком числа a перед ней: P11.

Непрефиксный код может быть однозначно декодируемым. Конечный граф
несовпавших хвостов даёт доказательство: важно достижение пустого хвоста,
а не наличие петли. В `(aa|abaa|aaaba)*` есть петля хвоста a, но нет
завершённой коллизии. Для произвольной регулярки дополнительно проверяется
однозначность внутреннего разбора каждого блока.

## Перенос в учебный тренажёр

Генерировать условия только вместе с проверяемым общим ключом. Разделять
происхождение, статус самостоятельности и проверку временем. Генератор
не должен сам оценивать по недоказанному ответу. Безопасные параметрические
семьи и ограничения переноса — `study/rk1-2026/trainer/GENERATION.md`.
Конечные тесты служат регрессией, не сертификатом регулярности предиката.
