# Предметная память

Этот каталог содержит только обезличенные сведения, нужные для решения задач
по теории формальных языков. Здесь нет журналов общения, идентификаторов,
времени публикации, сведений об участниках и привязки решения к конкретному
человеку.

Файлы:

- `COURSE-QA.md` — устойчивые уточнения требований и ответы на частые вопросы;
- `SOLUTION-PATTERNS.md` — методы, контрпримеры и типовые ошибки;
- `SCAN-REVIEW.md` — обезличенный итог визуальной проверки рукописных PDF;
- `PRIVACY.md` — правила пополнения безопасной памяти.

Эти заметки являются вторичным ориентиром. Формулировку задачи всегда задаёт
пользователь, а определения и требования сверяются с официальными материалами
курса в `corpus/txt/` и, при наличии локальных файлов, в
`references/teacher/`.
