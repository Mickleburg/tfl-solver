# TFL Solver для Claude Code

Канонические инструкции общие для Claude Code и Codex. Перед решением полностью
прочитай `skills/tfl/SKILL.md` и следуй ему. Если skill установлен
глобально и текущий каталог не является клоном, корень материалов указан самим
глобальным адаптером и также доступен через `tfl root`.

Актуальное состояние находится в `docs/PROJECT-STATE.md`, незакрытые вопросы —
в `docs/OPEN-GAPS.md`. Не используй этот адаптер как отдельную копию правил и
не добавляй сюда предметную логику: она должна оставаться в каноническом skill
или в `docs/recipes/`.
