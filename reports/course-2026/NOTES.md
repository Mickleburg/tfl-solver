### Что оракул говорит про полугруппу Цейтина

Копредставление со слайда 5 записывается как SRS дословно:

```
ac -> ca    ad -> da    bc -> cb    bd -> db
eca -> ce   edb -> de   cca -> ccae
```

`terminates()` немедленно даёт **петлю `cca → ccae`**: левая часть вложена
в правую, слово растёт, не повторяясь. Стоит развернуть ориентацию
армейским порядком (`ccae → cca` и так далее) — и система становится
завершимой. Отсюда предупреждение для отчёта: копредставление и система
переписывания — разные объекты, **ориентация соотношений выбирается,
а не читается из записи**, и от выбора зависит само наличие завершимости.

Дальше, впрочем, упирается пополнение: ни при одном из перебранных
приоритетов букв оно не сходится. Это ровно то, чего требует теорема
Цейтина, — проблема равенства в этой полугруппе неразрешима, поэтому
полной системы переписывания у неё быть не может. Закреплено в наборе
для оценки (`evals/suite.py`, случай `exam3-копредставление`).

## Что нужно к лекции 12 сентября

README перечисляет прямо:

1. автоматы Мили и алгоритмы над ними (из ДМ);
2. действие группы на множестве;
3. свободные группы, копредставления (они же представления посредством
   определяющих соотношений), и **Пример 1.78 из лекций ГН** — показать,
   что из этих соотношений следует коммутативность любых элементов,
   «это задачка не столько по алгебре, сколько по ТФЯ»;
4. граф Кэли группы.

Третий пункт — прямое задание, и оно нашего профиля: коммутативность
всех образующих влечёт коммутативность группы, а вывод соотношения
из соотношений — это переписывание.

**Условия в корпусе нет.** Искал по правилу §2d в трёх видах — «1.78»,
«коммутативн», «ГН» — ни в зеркале корпуса, ни в выжимке чата ничего.
Что такое «лекции ГН», из README не следует. Нужен либо сам источник,
либо формулировка примера от пользователя.

Под этот пункт написан `tfl/presentation.py`: копредставление
переводится в систему переписывания (для группы — с обратными буквами
и правилами свободного сокращения `aa⁻¹ = ε`), соотношения ориентируются
армейским порядком, система пополняется по Кнуту–Бендиксу, и проблема
равенства решается трёхзначно.

```python
from tfl.presentation import parse_presentation
p = parse_presentation("группа: a, b
aba^-1 = bb
bab^-1 = aa")
p.is_commutative()      # коммутативно ли
p.is_trivial()          # все ли образующие равны единице
p.equal("ab", "ba")     # проблема равенства, три исхода
```

Тонкость, ради которой всё и разделено: **равенство доказывается без
конфлюэнтности**. Совпадение нормальных форм — это уже готовая цепочка
соотношений, применённых в обе стороны, и пополнение для такого вывода
не нужно. А вот вывод «не равны» требует полной системы: иначе слова
могли бы сойтись где-то дальше.

Контрольная точка: классическое `⟨a, b | aba⁻¹ = b², bab⁻¹ = a²⟩`.
Пополнение на нём **расходится**, и всё равно оракул доказывает, что
группа тривиальна — обе образующие приводятся к пустому слову. Обратный
пример: `⟨a, b | a² = 1, b² = 1⟩` (бесконечная диэдральная) пополняется
до полной системы, и там `ab ≠ ba` — уже доказанно.
