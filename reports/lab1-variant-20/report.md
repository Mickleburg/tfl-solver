## 3. Локальная конфлюэнтность

Критических пар: **142**. Рассматриваются только наложения левых частей — непересекающиеся применения правил сходятся всегда.

**❌ нет** — критическая пара не сходится: слово «aaac» по правилу (aaa → aa) даёт «aac», а по правилу (ac → cc) — «aacc»; множества потомков вычислены полностью и не пересекаются

Контрпример:

```text
aaac
  ├─ по правилу aaa → aa  →  aac
  └─ по правилу ac → cc  →  aacc
```

Множества потомков обеих веток вычислены полностью и не пересекаются, поэтому свести их нельзя.

* То же, но связь направленная (ω′ →* ω либо ω →* ω′): **❌ нет** — «acba» переписывается в «ccab» в первой системе, а во второй они не связаны ни в одну сторону, и оба обхода пройдены целиком

Обратные правила удлиняют слова, поэтому классы почти всегда не помещаются в бюджет обхода целиком. Вывод «не эквивалентны» делается, только если класс той стороны, которой слова не хватило, вычислен полностью.

## 6. Инварианты для метаморфного тестирования

Ищутся инварианты вида `Σ cₓ·|w|ₓ mod m`. Такой инвариант сохраняется тогда и только тогда, когда для каждого правила `Σ cₓ·(|rhs|ₓ − |lhs|ₓ) ≡ 0 (mod m)`; это однородная линейная система, и её решения находятся точно, а не подбором.

Линейных инвариантов по модулям 2, 3, 5, 7 нет.

[ВРУЧНУЮ] Задание просит минимум два инварианта, так что нужны нелинейные: моноидные гомоморфизмы в матрицы, порядковые меры, число вхождений подслов. За нетривиальные — до +2 баллов.
