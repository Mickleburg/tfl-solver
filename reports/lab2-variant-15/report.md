## 2. Возможно малый НКА

Построение: позиционный автомат (Глушкова) на 13 состояний, затем склейка состояний с совпадающим правым языком → **6** состояний. Для сравнения, автомат Томпсона дал бы 46 состояний.

Граф — `nfa.dot` (позиционный автомат до склейки — `positional.dot`).

| состояние | a | b | финальное |
|---|---|---|---|
| 0 (старт) | {4,5} | {0,5} | да |
| 1 | ∅ | {2} |  |
| 2 | ∅ | {3} |  |
| 3 | {4,5} | {5} | да |
| 4 | {3} | {4} |  |
| 5 | {1} | ∅ |  |

### Оценка минимальности снизу

Обманывающее множество (треугольная версия теоремы Глайстера–Шаллита) размера **6**: γ_i ω_i ∈ L, а γ_j ω_i ∉ L при j < i. Значит, ни один НКА для этого языка не может иметь меньше 6 состояний.

| i | γ_i | ω_i |
|---|---|---|
| 1 | aabab | baa |
| 2 | abab | abbaba |
| 3 | bab | bba |
| 4 | babba | aabb |
| 5 | aaba | bbaa |
| 6 | ε | bbb |

Оценка снизу (6) совпала с числом состояний построенного автомата — **НКА минимален**.

## 3. Переключающийся (конъюнктивный) автомат

[ВРУЧНУЮ] **Инвариант** генератор не выдумывает: надо заметить свойство языка, которое проверяется отдельно от основной структуры. Преподаватель различает два вида — обычные (проверяются для всей строки сразу) и рекурсивные (для всех суффиксов после определённого сочетания букв).

Когда инвариант найден, автомат строится готовой конструкцией из `tfl/afa.py` — руками его собирать не нужно:

```python
from tfl.afa import conjunction, with_lookahead, disagreements
from tfl.automata import dfa_of

# обычный инвариант: И-ветвление в стартовой вершине
A = conjunction([dfa_of("<условие 1>", alphabet),
                 dfa_of("<условие 2>", alphabet)], alphabet)

# рекурсивный инвариант: проверка всего остатка слова
A = with_lookahead(reader=dfa_of("<основная структура>", alphabet),
                   checker=dfa_of("<условие на остаток>", alphabet))

print(A.summary())                       # размеры ПКА / НКА / ДКА
disagreements(A, dfa_of('b*((ab*a)*(aabb|(babb)*))*', alphabet), max_len=12)
```

Подробно — `docs/recipes/LAB-2.md`, §4. Произведение автоматов строить **не надо**: пересечение даёт `|Q₁|·|Q₂|` состояний, а ПКА на том же условии — `|Q₁| + |Q₂| + 1`, ради этого конструкция и нужна.

## 4. Расширенное регулярное выражение

[ВРУЧНУЮ] Требуются маркеры `^` и `$`. Разрешены `.`, `τ+`, `τ?`, опережающие `(?=…)` / `(?!…)` и ретроспективные `(?<=…)` / `(?<!…)` проверки, классы символов `[…]`.

Если упрощение сводится к академической регулярке, его можно проверить машинно:

```python
from tfl.automata import dfa_of, counterexample
counterexample(dfa_of('b*((ab*a)*(aabb|(babb)*))*'), dfa_of("<упрощение>"))  # None = равны
```
