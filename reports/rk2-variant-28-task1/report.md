# РК2 2025, вариант 28, задача 1 — наработки

**Условие.** Язык SRS `ba² → ba`, `ab → ba`, `a → ab` над базисом `aⁿbⁿaⁿ`.

Язык SRS над базисом — это замыкание базиса по правилам:
$$L = \{\,w \mid \exists n \ge 1:\ a^n b^n a^n \Rightarrow^*_T w\,\}.$$

Задачу писали двое, оба получили **1 балл из 5**, и ответы у них разные.
Преподаватель ни один не приняла, встречный вопрос на полях —
«можно ли получить $a^{n+1} b^n a$?». Ниже — то, что удалось установить
исполнением.

## Что опровергнуто

Обе студенческие гипотезы отвергнуты встречными примерами **в обе стороны**
(перебор замыкания до длины 9, `tfl/srs.py`):

| Гипотеза | Слово в языке, которое она отвергает | Слово, которое она принимает зря |
|---|---|---|
| `{aⁿbᵐ, m ≥ n ≥ 1}` (photo_112) | `aaabbba` | `ab` |
| `(a\|b)*b(a\|b)*a` (photo_166) | `aaabbbab` | `aaba` |

Первый столбец — доказательство: слова получены явной цепочкой переписываний.
Второй — опровержение при условии, что обход не пропустил путь через длинные
промежуточные слова; для `ab` это видно и вручную (единственное укорачивающее
правило `ba² → ba` оставляет в слове фактор `ba`, а в `ab` его нет).

## Что доказано

Три необходимых условия. Каждое проверено на **всех** шагах переписывания
из слов длины ≤ 7 — не «на выборке», а исчерпывающе по правилам.

**1. `ba` — фактор любого слова языка.**
Базис `aⁿbⁿaⁿ` содержит `ba` на стыке. Ни одно правило вхождение `ba`
не разрушает: `ab → ba` его создаёт; `ba² → ba` укорачивает хвост,
оставляя `ba`; `a → ab` вставляет `b` **после** буквы `a`, так что пара
`ba` остаётся смежной. Нарушений: **0**.

**2. `|w|_a ≤ 2·|w|_b`.**
Мера $d(w) = 2|w|_b - |w|_a$ на базисе равна нулю: $2n - 2n = 0$.
Ни одно правило её не уменьшает — `ab → ba` сохраняет, `a → ab`
добавляет `b` (то есть $d{+}2$), `ba² → ba` убирает `a` (то есть $d{+}1$).
Шагов, уменьшающих меру: **0**. Значит $d(w) \ge 0$ всюду в языке.

**3. Начальный блок из `a` не удлиняется.**
`ab → ba` его укорачивает, `a → ab` внутри блока разрезает его буквой `b`,
`ba² → ba` требует `b` слева и блока не касается. Шагов, удлиняющих
начальный блок: **0**. Следствие: слово с начальным блоком длины `k`
может прийти только из базиса с `n ≥ k`.

Вместе с условием 2 (нужно $n \ge |w|_a/2$) и тем, что `b` только
добавляются (нужно $n \le |w|_b$), получается проверяемое условие:
$$\max\Bigl(k,\ \bigl\lceil |w|_a/2 \bigr\rceil\Bigr) \le |w|_b,$$
где `k` — длина начального блока из `a`.

## Чего не хватает

Три условия **не достаточны**. Среди слов длины ≤ 10 им удовлетворяют
367 слов, которых в вычисленном замыкании нет; самое короткое — `aabab`.

Разбор `aabab` вручную показывает, чего не хватает формально: начальный
блок `aa` требует базиса с `n ≥ 2`, а сохранить его нетронутым можно,
только не применяя правил на стыке; тогда хвост эволюционирует из `bbaa`,
а `bab` из `bbaa` не получается — `ab → ba` двигает `b` лишь **влево**,
и обратного шага нет.

То есть нужен четвёртый инвариант, учитывающий **порядок** букв, а не только
их количество: b-шки монотонно уходят влево, и это ограничивает достижимые
перестановки. Такого инварианта пока нет.

**Статус: точного описания языка нет.** Есть три доказанных необходимых
условия и опровержение обоих известных ответов.

## Воспроизведение

```python
from tfl.srs import parse_srs

T = parse_srs("baa -> ba\nab -> ba\na -> ab\n")
T.reachable("aabbaa", max_len=10)      # замыкание базиса при n = 2
```
