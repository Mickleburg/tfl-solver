### photo_116–118 — вариант 15
Задача 1: грамматика `S→aSbSb, S→aSa, S→a`, условие «букв `a` вчетверо

**Красивое решение (инвариант чётности):** вводится `I(w) = |w|_a − 2|w|_b`.

*числовой инвариант, сохраняемый правилами грамматики, против числового
условия отбора*. Проверяется оракулом перебором выводов.

### photo_141–144 — вариант 11, разложение условия `≠`
Приём: условие с `≠` разбивается на объединение двух неравенств.
`L = L< ∪ L>`, где `L< = {w | k+2 < 2Σnᵢ}`, `L> = {w | k+2 > 2Σnᵢ}`.

а объединение КС-языков — КС. **`≠` не считается стеком напрямую,
объединение двух строгих неравенств — считается.**

АГ варианта 11: `S→AaaSaaA ; A₂.attr < A₁.attr`, `S→AbSA ; A₂.attr > A₁.attr`,

### photo_155–157 — инвариант чётности, полный вариант
Грамматика `S→aSaSa | bSb | b`, условие `|w|_a = |w|_b`.
`A(w) = |w|_a`, `B(w) = |w|_b`, `D(w) = B(w) − A(w)`.
* `S→b`: `D = 1` — нечётно;
* `S→bSb`: `D(w) = D(u) + 2` — нечётность сохраняется;
* `S→aSaSa`: `D(w) = D(u) + D(v) − 3` = нечёт + нечёт − 3 = нечётно.

Индукция по выводу ⇒ `D(w)` нечётно всегда. Условие `|w|_a = |w|_b`
даёт `D = 0` — чётно. Противоречие ⇒ **L = ∅**.

Закрытие: пустой язык КС (`S→SS`, стартовый `S`, ничего не выводится)
и регулярен (регвыражение `∅`, ДКА из одного непринимающего состояния).
«Лемма о накачке не нужна, поскольку язык оказался пустым.»

Это **второй** вариант с тем же приёмом (первый — photo_116).
Похоже, «грамматика + числовое условие ⇒ инвариант ⇒ пустой язык» —
не случайность, а заложенный в РК2 сюжет.

1. **Инварианты SRS:** буква `b` встречается ровно один раз; все `c`

   никогда не растёт.
2. **Замыкание базиса:** применяя `aba→cab` ровно `n` раз, `b` уезжает
   в конец; затем `ac→ca²` нормализует, сдвигая все `c` влево.
   Получается `cⁿ a^{M(n)} b`, и рекуррентность даёт
   **`M(n) = 2ⁿ(n−1) + 1`** — экспоненциальный рост.
3. **Пересечение с регулярным** `R = c*a*b`:
   `L ∩ R = {cⁿ a^{2ⁿ(n−1)+1} b | n ≥ 1}`.
4. **Накачка** в форме `w = x₁y₁zy₂x₂`: если `y₁y₂` задевает `b` — рушится
   инвариант «ровно одна `b`»; если `y₁y₂` состоит из `a` — число `a`
   меняется не более чем на `p`, а при фиксированном `n` оно обязано быть
   ровно `2ⁿ(n−1)+1`, и соседние значения отличаются на
   `f(n) − f(n−1) = n·2^{n−1} > p`. Противоречие.

Ответ: **не КС**. Схема «инварианты → замыкание → пересечение с регулярным
→ накачка» и есть шаблон задачи 1.

### photo_161–162 — теорема Париха и «условие схлопывается»

квадратом**. Дальше — не накачка, а **теорема Париха**: образ Париха
КС-языка полулинеен, а `{4t² + 1 | t ≥ 0}` — нет. Значит язык не КС.

**Этого приёма в проекте нет.** См. `docs/OPEN-GAPS.md`.

Задача 2 той же работы: `{w₀ uᴿ w₁ u w₂ | |w₀| < 3 & |u| > 0 & |u| > |w₀|}`.
Поскольку `|w₀| < 3`, всё условие **схлопывается в регулярное**:
`w ∈ L ⟺ ∃ i ∈ {0,1,2} и позиция q ≥ 2i+3, где символ на позиции `i+1`
совпадает с символом на позиции `q`». Ограниченный параметр под
квантором существования — повод проверить, не стал ли язык регулярным.

### photo_168–170 — вариант 17 (баллы 2|5|·)
SRS `{a→b, b³a³→ab}` над базисом `aⁿb^{2n}`. Наблюдение студента: правило

### photo_172–178 — вариант 9, работа на 5|·|5 (и пометка про GPT)

### photo_181–184 — вариант 1 (баллы 5|2|·)
SRS `{aa→aba, ba→abb}` над `(ab)*`. Одним правилом `ba→abb` получается

### photo_182 — самая важная красная пометка во всей пачке
Студент пересёк язык с регулярным, построил для **пересечения** ДМП-автомат
и заключил «язык DCFL».

> **«А почему анализируете только пересечение? Оно может привести
> к переходу NCFL → DCFL в общем случае!»**

Правило, которое отсюда следует и которое должно быть зашито в агента:
**пересечение с регулярным — приём односторонний.** Из «L ∩ R не лежит в K»
(и замкнутости K относительно пересечения с регулярным) следует
«L не лежит в K». Обратное — из «L ∩ R лежит в K» — **не следует ничего**.

### photo_185–186 — «свести базис к одному слову»
SRS `ac→c`, `c→aca`, `a²c→cb` над базисом `aⁿcaⁿc`. Ход:
1. число букв `c` — **инвариант**;
2. языки, порождённые из `aⁿcaⁿc` и `aᵐcaᵐc`, **совпадают**, потому что
   произвольное число `a` добывается из первой же `c` правилом `c→aca`;
3. значит достаточно разобрать язык, порождённый из **одного слова `cc`**;
4. `cc → aacaac → aacbb → ccb`, `cc → caca → cca` ⇒ блоки между `c`
   и суффикс после последней `c` пробегают `(a|b)*`, а блок до первой `c` —
   только `a*`.

Ответ: `a* c (a|b)* c (a|b)*` — **регулярный**.

### photo_187–188 — вариант 1, задача 3: эталон для RK2-C
АГ (в записи студента): `S→S' ; S'.a ≥ S'.b`, `S'→TaS'`, `S'→T`,
`T→TBa ; T₀.a := T₁.a+1, T₀.b := T₁.b+B.b`, `T→ε ; 0,0`, `B→bB ; +1`, `B→ε ; 0`.

Схема решения на 5:
1. **Понять, что считают атрибуты.** Здесь `.a` и `.b` — просто числа
   букв `a` и `b`, поэтому корневое условие превращается в `|w|_a ≥ |w|_b`.
2. **Выписать язык нижележащей КС-грамматики** как регулярное выражение:
   `B = b*`, `T = (b*a)*`, `S' = ((b*a)*a)*(b*a)*`, и это упрощается до `(b*a)*`.
3. `L(G) = {w из L((b*a)*) : |w|_a ≥ |w|_b}`.
4. **КС** — как пересечение КС-языка `{w : |w|_a ≥ |w|_b}` с регулярным `(b*a)*`.
5. **Не регулярен** — таблица Майхилла–Нероуда: строки `b, bb, …, bⁿ`,
   столбцы `a, aa, …, aⁿ`, все строки различны ⇒ классов бесконечно много.

### photo_191–192 — АГ с НАСЛЕДУЕМЫМИ атрибутами
```
S  → aS'a | bS'b   ; S'.inh_attr := 1
S' → aS'a | bS'b   ; S'1.inh_attr := S'0.inh_attr + 1
S' → T             ; T.inh_attr := S'.inh_attr
T  → bT            ; T1.inh_attr := T0.inh_attr + 1
T  → cT            ; T1.inh_attr := T0.inh_attr + 1
T  → aT            ; T1.inh_attr := T0.inh_attr
T  → ε             ; T.inh_attr == 0
```
Атрибут **передаётся вниз** от корня к листу, а условие проверяется
на правиле `T → ε`. Значит `tfl/attr.py` обязан поддерживать не только
синтезируемые, но и **наследуемые** атрибуты, и условие может стоять
на правиле-листе.

Решение: `L = {w v wᴿ}` с арифметическим условием на `|v|_a, |v|_b, |v|_c`
относительно `|w|`; дальше пересечение с `(a|b)*c(a|b)*c(a|b)*` и накачка.

## Итог: чему учит пачка

**Ошибки, за которые снимают баллы** (по красным пометкам):

| Ошибка | Сколько раз | Чем лечится в агенте |
|---|---|---|
| Разбор случаев в накачке неполон («я разложу иначе — и всё») | 5 | `tfl/pump.py` перебирает **все** разбиения |
| Замыкание SRS посчитано не до конца («переписывание не исчерпывающее!») | 2 | полный обход достижимых слов в `tfl/srs.py` |
| Слово-свидетель не принадлежит языку | 2 | `word in language` одной строкой |
| Автомат принимает лишнее («`ab³` примет») | 2 | `PDA.accepts` против предиката, `disagreements` |
| Ответ дан не на весь вопрос («детерминизм?») | 1 | чек-лист вопросов класса задачи |
| Из «L ∩ R лежит в K» выведено «L лежит в K» | 1 | правило односторонности пересечения |
| Атрибутное условие проигнорировано | 1 | интерпретатор АГ |

**Приёмы, за которые ставят 5:**

1. Инварианты SRS → точное замыкание базиса → пересечение с регулярным
   → накачка (варианты 9, 13).
2. Числовой инвариант грамматики против числового условия ⇒ **пустой язык**
   (вариант 15 и работа по `S→aSaSa|bSb|b`).
3. Сведение базиса к одному слову, если из него добывается всё остальное.
4. Для АГ: понять, что считают атрибуты → выписать регулярное выражение
   нижележащей грамматики → язык = регулярное ∩ арифметическое условие.
5. Против КС, кроме накачки: **теорема Париха** (полулинейность образа)
   и **гомоморфизм в унарный алфавит** с разрывом между квадратами.
6. Разложить `≠` на объединение `<` и `>`, чтобы посчитать стеком.
7. Для DCFL: замкнутость относительно **дополнения** и **пересечения
   с регулярным**; «метод неожиданного конца» против LL(k).
