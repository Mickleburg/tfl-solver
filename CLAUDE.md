# TFL-2026 — агент для решения задач по теории формальных языков

Рабочая директория курса ТФЯ (ИУ9, МГТУ им. Баумана). Здесь собраны материалы
преподавателя, учебная литература и 21 репозиторий с решениями старшекурсников.
Цель проекта — агентский цикл (скилл), решающий задачи РК, лаб и экзамена.

## Правила работы

- **Условие задачи берём только из `FormalLanguageTheory/`** (репозиторий
  преподавателя). Решения студентов — образец оформления, не источник истины:
  ошибки там встречаются регулярно.
- **Грепаем `corpus/txt/`, а не PDF.** Зеркало строится
  `python tools/extract_corpus.py`; сканы (`kind=SCAN` в `corpus/INDEX.tsv`)
  читаются только рендером: `python tools/extract_corpus.py --render FILE.pdf 1 5`.
- **Каждая гипотеза проверяется исполнением.** Утверждение, не прогнанное через
  оракул, помечается в отчёте `[НЕ ПРОВЕРЕНО]`.
- Отчёты — Markdown с MathJax-формулами (это +1 балл во всех лабах).

## Запуск

```bash
export PYTHONIOENCODING=utf-8 PYTHONPATH=.     # консоль Windows иначе в CP1251
python -m pytest tests/ -q
```

## Состояние

* **S-0 готово** — инвентаризация корпуса, таксономия задач, план.
* **S-1 готово** — ядро оракулов для регулярных языков:
  `tfl/regex.py` (академические регексы, производные Брзозовского),
  `tfl/automata.py` (НКА/ДКА, детерминизация, минимизация, булевы операции,
  эквивалентность со свидетелем), `tfl/myhill.py` (таблица классов,
  обманывающие множества), `tfl/words.py`. 162 теста, все зелёные.
  Сводка по 28 вариантам ЛР2 — `evals/lab2_2025_report.md`.
* **S-2 готово** — позиционный автомат Глушкова и редукция НКА (`tfl/glushkov.py`),
  генератор отчёта `tools/lab2_report.py`, рецепт `docs/recipes/LAB-2.md`,
  образец `reports/lab2-variant-15/`. 254 теста.
* **Дальше — S-3**: SRS и ЛР1 (`tfl/srs.py`).
  См. таблицу сессий в `docs/03-AGENT-PLAN.md`, §7.

Две тонкости, уже стоившие ошибки и закреплённые тестами:

1. `len(dfa)` — состояния без ловушки, `dfa.class_count()` — классы
   Майхилла–Нероуда вместе с ловушкой. Путаница даёт расхождение на единицу.
2. Для оценки размера НКА нужна **треугольная** версия теоремы
   Глайстера–Шаллита (`extended_fooling_set`); симметричная систематически
   занижает оценку.

**Не хватает для старта решения задач:** номер варианта пользователя
(номер в списке группы) — от него зависит выбор задачи во всех лабах и РК.
