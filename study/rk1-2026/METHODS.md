# Учебные опоры

Это краткий справочник, а не список ответов к задачам. Материал выбирается
по зависимости конкретного решения, а не по наличию теоремы в большом учебнике.

## Обозначения

`ε` — пустое слово, `Σ*` включает его, `Σ+` — только непустые слова.
`a+` в выражении — сокращение `aa*`, а не операция объединения.
`|w|_p` — число вхождений непрерывного подслова `p`, включая перекрывающиеся:
`|aaa|_aa=2`. `wᴿ` — реверс. В языках с разбиением оно существует, если
прямо не сказано обратное. Соотношение `u=v` допускает обе стороны;
правило `u→v` — только указанное направление.

## Регулярность

Сначала проверь смысл условия: кванторы, пустые слова, отрицание дизъюнкции,
крайние случаи. Иногда ограничения вместе покрывают все показатели.

Язык регулярен, если его распознаёт конечный автомат. Опиши, какую конечную
информацию нужно помнить, задай начальное состояние, переходы и допуск.
Регулярные языки замкнуты относительно объединения, пересечения и дополнения.
Дополнение всегда берётся относительно явно выбранного универсального языка.

Теорема Майхилла–Нероуда: `x~y`, если для каждого продолжения `z` одновременно
`xz∈L ⇔ yz∈L`. Для нерегулярности достаточно бесконечного семейства префиксов,
любые два из которых различаются некоторым продолжением. Суффикс может
зависеть от выбранной пары. Диагональные плюсы, диагональные минусы и
ступенчатая таблица одинаково годятся, если строки попарно различаются.
Конечная таблица лишь иллюстрирует общее доказательство.

## Автоматы и выражения

В ε-НКА сначала учитываются все ε-переходы без чтения буквы. При детерминизации
состояние — множество достижимых состояний НКА; после буквы снова берётся
ε-замыкание. Допускающие множества содержат хотя бы одно исходное финальное.
Строятся достижимые множества; пустое множество при необходимости — ловушка.

Пересечение ДКА: состояние `(p,q)`, переход по одной букве обновляет оба
компонента, допуск требует финальности обоих. Для дополнения нужен полный
ДКА: затем финальные состояния меняются на нефинальные и наоборот.

Минимизация: сначала разделить финальные и нефинальные; затем уточнять группы,
если по букве состояния идут в разные группы. Для минимальности результата
нужны достижимость и различимость оставшихся состояний.

Позиционный автомат: пометить каждое вхождение буквы, вычислить `First`,
`Last`, `Follow`; из нового начала перейти в `First`, затем по `Follow`.
Метка перехода — буква целевой позиции. Финальны `Last` и начало, если
выражение допускает ε.

Лемма Ардена: если `ε∉A`, уравнение `X=AX∪B` имеет единственное решение
`X=A*B`. Для `X=XA∪B` решение `BA*`. Не менять порядок множителей.
По НКА можно также описывать первый вход в финальную вершину и возвращения.

## Разбор выражения и кодирование

Однозначность выражения: каждому слову языка соответствует один полный разбор
по альтернативам, итерациям и границам конкатенации. Это не 1-однозначность
позиционного автомата. Один пример с двумя разборами опровергает однозначность.
Число разборов нельзя оценить сверху по нескольким найденным примерам.

Префиксный код однозначно декодируется, но обратное неверно. Морфизм задан
образами букв и удовлетворяет `h(uv)=h(u)h(v)`. Инъективность кодировки —
единственность прообраза; она сама по себе не гарантирует малую задержку.
Для неограниченной задержки покажи сколь угодно длинные общие префиксы кодов
слов с разными первыми буквами, а не только несколько длинных примеров.

## Переписывание

Завершимость: бесконечных выводов нет. Достаточна мера в `N`, лексикографическая
мера в фиксированном `N^k` либо иной явно обоснованный фундированный порядок,
строго убывающий в любом контексте. Рост длины не означает незавершимость.

Конфлюэнтность: любые два потомка одного слова имеют общего потомка.
Если система завершима, достаточно локальной конфлюэнтности (лемма Ньюмана).
Для строковых правил локальные конфликты ищутся по наложениям и включениям
левых частей; непересекающиеся шаги переставляются. У образцов переменные
могут обозначать произвольные слова, в том числе ε, если это разрешено.

Маркерная симуляция: отделить чистую строку от промежуточной, описать фазы,
доказать соответствие завершённых проходов шагам исходной системы. Тупиковая
ветвь с маркером не является новым чистым результатом. Эквивалентность чистой
достижимости не переносит автоматически конфлюэнтность на все строки SRS.

## Копредставления и префиксные грамматики

В полугруппе рассматриваются непустые слова; в моноиде разрешено ε как единица.
Конечный список представителей даёт только верхнюю оценку. Для точного числа
элементов нужно доказать различие представителей: моделью, действием на
конечном множестве или завершённой конфлюэнтной системой нормальных форм.

Префиксное правило `u→v` действует как `uz→vz`, только на начале слова.
По ДКА выбираются представители состояний; обращение рёбер позволяет
построить грамматику без потери суффикса. В размеченном правиле
`(T_i,T_j):u→v` нужно `∀z: uz∈T_i ⇒ vz∈T_j`, не одно проверенное слово.

## VPL

Роль буквы фиксируется заранее: вызов кладёт символ, возврат снимает,
внутренняя буква стек не меняет. На дне возврат не снимает символ дна.
Приём — по конечному состоянию. При двух буквах есть девять назначений ролей.
Если нет вызовов или нет возвратов, память стека не даёт нерегулярности.

Необходимое условие курса: для VPL двусторонняя конгруэнция
`x≡y ⇔ ∀u,v: uxv∈L ⇔ uyv∈L` имеет конечный индекс на правильно
сбалансированных словах. Не переносить это на все обычные правые классы VPL.
Нерегулярность сама по себе не исключает VPL.

При пересечении с регулярным автоматом роль букв не меняется: достаточно
хранить его состояние в управляющем состоянии VPA. Если на всех префиксах
слов фильтра высота стека ограничена константой, варианты стека конечны;
их можно также включить в состояние конечного автомата. Это объясняется
конструкцией, без обращения к КС-лемме о накачке.

## Дополнительные предпосылки

Для H01–H02 не приложено полного доказательства существования сколь угодно
длинных слов, избегающих соответствующих повторов. Не считать конечный
генератор таким доказательством. Для F03 сначала уточняется определение
«почти однозначности»; доказанный рост числа разборов от этого не зависит.
