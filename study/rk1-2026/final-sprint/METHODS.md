# Краткая памятка по 12 типам

Справочник для преподавателя-чата. Не показывать алгоритм текущей задачи
автоматически до попытки. Это не лист ответов на самом РК.

## 1. Критические пары

Для каждой упорядоченной пары левых частей l₁,l₂ проверить совпадения
непустого собственного суффикса l₁ с префиксом l₂. Проверить также все
включения одной левой части в другую, в том числе правила с одинаковыми
левыми частями и разными правыми. Самоналожения обязательны. Если
l₁=xs, l₂=sy, перекрывающее слово xsy даёт r₁y и xr₂.
Включение l₁=xl₂y даёт r₁ и xr₂y. Независимые непересекающиеся шаги
переставляются и не дают критического конфликта. Показывать исходное слово
и обе одношаговые ветви; нормализовать ветви вместо этого недостаточно.

## 2. Завершимость

|w|_p считает вхождения непрерывного подслова p, включая перекрытия.
Подбирать сначала счётчики букв, затем пар и более длинных подслов;
при необходимости фиксированный лексикографический вектор в N^k.
У каждого правила первая изменившаяся компонента должна уменьшаться.
Обязательно считать вхождения, пересекающие левую и правую границы редекса.
Рост длины не опровергает завершимость. Неудачный подбор счётчиков ничего
не доказывает. Для отрицательного ответа нужен бесконечный вывод:
замкнутый цикл достаточен, но a→aa даёт бесконечный рост вообще без цикла.
Нельзя переориентировать направленные правила SRS ради доказательства.

## 3. Конечность моноида

В копредставлении соотношения — равенства: их можно ориентировать по
фундированному порядку, совместимому с контекстом. Новые правила выводить
из соотношений через критические пары; каждое должно сохранять конгруэнцию.
Затем интерредуцировать и снова проверить конфликты. Завершимость и
соединяемость всех критических пар дают единственные нормальные формы.

Из ε строить дерево правых продолжений: к каждому представителю приписывать
каждую образующую, сокращать, повтор уже встречавшегося результата замыкать
на него. Конечное замкнутое множество, содержащее ε, даёт конечность.
Для точного числа нужны разные классы, а не только список представителей.
Бесконечную ветвь неприводимых слов обосновать либо полной системой, либо
разделяющим инвариантом/моделью. У неполной системы разные нормальные формы
ещё могут задавать один элемент. Бесконечное пополнение не означает
бесконечности моноида. Полугруппа не включает ε, моноид включает.

## 4. Автомат → выражение

Можно выбрать: первый вход и циклы возвращения; систему уравнений с Арденом;
исключение состояний. Для языка продолжений из q:
X_q = (ε, если q финально) ∪ ⋃ cX_r по всем переходам q-c→r.
Арден: X=AX∪B даёт X=A*B при ε∉A; X=XA∪B даёт X=BA*.
Не менять порядок множителей. При исключении k метка i→j меняется на
R_ij | R_ik(R_kk)*R_kj. Принимать все и только пути от начала к допуску.

## 5. Выражение → автомат

Для позиционного метода различить каждое вхождение буквы. Вычислить
Nullable, First, Last, Follow по дереву выражения. Новое начало S переходит
в First; позиция i — в Follow(i), метка равна букве целевой позиции.
Финальны Last и, при Nullable, S. Недетерминизм разрешён, если нужен НКА.
Томпсон тоже допустим, когда условие не требует иной конкретный метод.

## 6. Минимальность

Убрать недостижимые состояния; при необходимости дополнить ДКА ловушкой.
Начальное разбиение F / (Q\F). Делить группы по вектору групп назначений
по всем буквам до устойчивости. Построить фактор-автомат; обосновать
достижимость и различимость оставшихся классов. Для различимости можно
предъявлять продолжения, не обязательно строить ещё одну большую таблицу.

## 7. Детерминизация

Начало E({q₀}), где E — ε-замыкание. Переход S по c равен
E(⋃_{q∈S} δ(q,c)). Финальны множества, пересекающие исходное F.
Повторять до замыкания всех достижимых множеств. ∅ — ловушка при её
достижимости либо при явном требовании полного ДКА. Не брать лишь одно
удобное положение исходного НКА и не забывать замыкание после буквы.

## 8. Пересечение

Из начальной пары (q₀,p₀) строить достижимые пары; по каждой букве двигать
обе компоненты. Допуск F₁×F₂, а не «хотя бы одна финальна». Для разных
алфавитов сначала фиксировать общий универсум и полный смысл переходов.

## 9. Дополнение

Уточнить универсум Σ* или Σ+. Разобрать отрицание условия и перекрытия
подслов. Можно сразу дать выражение нарушения. Общий путь: НКА языка →
ДКА → полный ДКА → инверсия допуска. Просто инвертировать F у НКА нельзя.
Неудачный один разрез не опровергает существование другого разреза.

## 10. Регулярность

Сначала упростить условия, проверить ε и нулевые показатели. Для
положительного ответа — конечная память, автомат или выражение. Для
отрицательного — семейство x_n, где любые разные x_n,x_m различает некоторое
z: ровно одно из x_nz,x_mz принадлежит L. Суффикс может зависеть от пары.
Конечная таблица не заменяет общего доказательства Майхилла–Нероуда.
Пересечение с регулярным позволяет переносить нерегулярность пересечения
на исходный язык, но не наоборот. Неограниченная разность счётчиков сама
по себе не доказывает нерегулярность её нулевого уровня.

## 11. Неоднозначность

Разбор фиксирует альтернативы, число повторений и границы конкатенации.
Для отрицания однозначности достаточно одного слова с двумя полными
разборами. Для доказательства однозначности нужны вынужденные границы,
например префиксный код блоков и однозначно отделённый конечный суффикс.
Детерминированный позиционный автомат — достаточный критерий однозначности;
недетерминированный — не достаточный критерий неоднозначности.

Шаблоны для поиска: два разных цикла p-w→p по одному непустому w в
позиционном НКА, на достижимом и ведущем к допуску состоянии, дают повторяемый
выбор разборов. Другой тип — перенос границы в (w₁w₂)*w₁(w₂w₁)*:
части могут передавать одинаковый фрагмент друг другу. Это ориентиры поиска,
не повод объявлять произвольную похожую запись неоднозначной без свидетеля.
Не заменять проверку выражения проверкой его уже детерминизованного ДКА.

## 12. Эквивалентность

Для опровержения проверить короткое различающее слово, обязательно ε.
Для доказательства — описание одного и того же языка, включения в обе
стороны, тождества или полный автоматный алгоритм. Если построены полные
ДКА, в произведении не должна достигаться пара с ровно одной финальной
компонентой. x*(yx*)*=(x|y)* — полезное семинарское тождество.
Совпадение на конечном списке слов не доказывает эквивалентность.

## Письменный ответ под лимит

За первую минуту: объект, метод, каркас ответа. Затем основное построение;
последние 2–3 минуты — границы, ε, полнота и оформление вывода. К концу
10 минут сдавать имеющийся корректный ход, не держать всё только в черновике.
Не заявлять готовый вывод, если доказана лишь часть. На проверке возможны
разные методы: оценивается корректность, а не буквальное совпадение с ключом.
