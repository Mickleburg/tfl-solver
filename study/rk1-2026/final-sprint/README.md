# РК1: короткий маршрут по 12 типам задач

Это отдельный комплект для последних одного–двух дней подготовки, а не
замена полного семинарского архива. В нём 26 карточек: 20 основных и 6 резервных.
Цель — уметь начать каждый тип и сдать понятное письменное решение за 10 минут,
а не последовательно перечитать все старые задачи.

## Что загрузить в новый чат

Прикрепи `TASKS.md`, `KEYS.md`, `METHODS.md`, `PROGRESS.md`.
Скопируй текст `START-PROMPT.md` в сообщение. `README.md` прикреплять не нужно.
Не открывай `KEYS.md`, если не хочешь заранее увидеть ответы.

В персональной локальной копии `PROGRESS.md` уже может быть заполнен.
Не заменяй его пустым шаблоном из этой папки. Старый чат не имеет общей памяти
с новым: переносит её только явно приложенный прогресс.

## План без перегрузки

1. Сначала незнакомые блоки: T11-A, T11-B, T11-C; T01-A;
   T02-A, T02-B, T02-C; T03-A, T03-C.
2. Затем автоматные процедуры: T04-A, T07-A, T06-A, T09-A, T09-B.
3. Затем T12-A, T12-B, T10-A, T10-B. T05-A и T08-A — короткая
   проверка уже знакомых конструкций, а не новый длинный курс.
4. После одной самостоятельной удачи на тип не решать подряд все его резервы.
   После помощи вернуть задачу через другой блок или на следующий день.
5. В конце — смешанные письменные попытки по одной задаче на 10 минут.
   Выбирать сначала типы без самостоятельного подтверждения, затем ошибочные.

Практический бюджет: несколько окон по 45–60 минут в первый день и несколько
во второй, с перерывами. Не требуется заниматься всё доступное календарное
время. Если есть только 3–4 часа, пройти по одной задаче каждого типа:
T01-A, T02-A, T03-A, T04-A, T05-A, T06-A, T07-A, T08-A,
T09-A, T10-B, T11-A, T12-A; остаток отдать обнаруженным пробелам.
Это сокращение покрытия, а не обещание полной готовности.

Вне текущего маршрута: кодировки, VPL, магазинные автоматы, маркерная
симуляция образцов, отдельное конструирование префиксных грамматик,
исследовательские задачи без полного ключа. Они не входят в переданные
12 типов. Вернуться к ним можно по отдельной просьбе.

## Формат РК, переданный для этого комплекта

- Два отвечающих одновременно; каждому ровно одна задача известного типа.
- На выдачу задания — 1 минута, на письменное решение — 10 минут.
- Для зачтённого ответа объявлен диапазон 10–15 баллов.
- После первых пяти минут можно попросить проверку заготовки или небольшую
  подсказку; объявленный штраф — 1–2 балла.
- Не сдано к концу 10 минут — 0. Неполная сданная работа может получить зачёт,
  но это не гарантируется. Метод студент выбирает сам.

Точной рубрики баллов нет: чат не назначает официальный балл за свою оценку.
Таймер запускает студент; чат не обещает сам сообщить о пяти или десяти минутах.

## Источники и границы

Основные источники — карточки полного `study/rk1-2026/` и подтверждённые
условия семинара 17.10. T01-B и T02-C — проверенные учебные примеры из
`tests/test_srs.py`, T03-C — пример коммутативного копредставления из
`tests/test_presentation.py`, рассматриваемый именно как моноид.
T06-B — автомат из E03 с отдельным требованием о минимальности.
Эти адаптации явно отмечены, не выдаются за новые семинарские задачи.

Схемы полностью заданы переходами. У T03-B сохраняется исходное требование
о группе; поскольку образующие обратимы, задача одновременно иллюстрирует
конечность моноида. C01 не подменён моноидом: исходная карточка — о полугруппе
без пустого слова и поэтому не включена в короткую очередь.

Ключи дают доказательства, а не вердикты по конечному перебору. Для T03
бесконечно много неприводимых слов означает бесконечность моноида только
после обоснования их различия. Неудачный подбор меры не доказывает
незавершимость SRS; бесконечный вывод не обязательно содержит замкнутый цикл.
