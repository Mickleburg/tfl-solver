# Как добавлять новые задачи

Это инструкция преподавателю-чату, а не набор ответов для просмотра заранее.
Генерация разрешена командой «новая задача» или явным согласием ученика.
Без неё использовать готовые карточки. Новые условия не являются официальными.

## Проверка до выдачи

1. Задать алфавит, области параметров, возможность ε, перекрытия подслов,
   кванторы и полное требование. Выбрать один проверяемый учебный приём.
2. Подготовить общий ключ и обе стороны всех упрощений. Для отрицательного
   ответа выписать x_i и z_i, а также принадлежность перекрёстных слов;
   проверить, не допускают ли они другого разбиения. Для положительного —
   точное выражение, инвариант ДКА или доказанное равенство простому языку.
3. Если доступны инструменты, сопоставить буквальный предикат с конструкцией
   на коротких словах, а конечные автоматы — точно по произведению.
   Никакое конечное совпадение не делает общий ключ доказанным.
4. Если общего доказательства нет, выбрать более простую задачу из семьи
   ниже. Не давать ученику непроверенный вердикт и не оценивать по нему.
5. Выдать только условие, нейтральный заголовок и N-ID. Сохранить происхождение,
   параметры, подсказки двух уровней, доказательство и допустимые способы
   отдельно. Не включать ответ или категорию регулярности в название.

## Разрешённые небольшие семьи для регулярности

| Семья | Параметры и доказательная опора |
|---|---|
| Остатки | `|w|_a≡k|w|_b+r (mod m)`, 2≤m≤7, 1≤k<m, 0≤r<m. ДКА помнит разность mod m, старт 0, допуск r. |
| Связанные счётчики | `|w|_a=k|w|_b+r`, 1≤k≤4, 0≤r≤2. Для нерегулярности x_i=a^(ki+r), z_i=b^i. Не подменять равенство сравнением остатков. |
| Разность переходов | `|w|_ab−|w|_ba=d`, d∈{−1,0,1}. Выразить по крайним буквам; ε проверить отдельно. При d=0 ответ включает ε. |
| Серии | `|w|_(b^k)=|w|_(b^(k+1))`, 1≤k≤4. Вклад серии длины r равен 1 при r≥k, иначе 0; язык избегает b^k. Для k=1 остаётся a*. |
| Движущийся разрез | `{uv : |u|_(a^k)=|v|_b}`, 1≤k≤4, u,v∈Σ*. Разность идёт от ≤0 к ≥0 шагами 0/1: L=Σ*. Два произвольных подслова вместо a^k и b так заменять нельзя. |
| Растущие промежутки | `{a^(n(n+c)):n≥0}`, 0≤c≤4. Разность соседних длин 2n+c+1 не ограничена; противоречие конечной периодичности однобуквенного ДКА. |
| Разность квадратов | `{a^(x²−y²+4t):x≥y≥0,t≥0}` и без t. Ключ R02/G07: ровно остатки 0,1,3 mod 4. Не менять произвольно ограничения на x,y. |
| Позиция маркера | `{u ab v : |u|+c<|v|}`, 0≤c≤3. В a^(i+1)b^(j+1) единственное ab, условие i+c<j. x_i=a^(i+1), z_i=b^(i+c+2), диагональ положительна, при h>i — отрицательна. |

Для разнообразия можно менять a↔b, применять обращение ко всему языку и
корректно переносить ключ. Биекция букв и обращение сохраняют регулярность
и нерегулярность. Не путать обращение всего слова с отдельной заменой w на
wᴿ внутри формулы. Не объявлять объединение с регулярным языком нерегулярным
только из нерегулярности одной части. Не переставлять ограничения непустоты.

Не генерировать десять почти одинаковых условий подряд. Чередовать конечную
память, выбор разреза, арифметику длин и различающие продолжения, используя
ошибку ученика как учебную цель. В контрольном раунде не раскрывать семейство.
Для остальных типов сначала достаточно запаса TASKS.md. Дополнительные
автоматы задавать полной таблицей, SRS — точными направленными правилами;
их новые ключи требуют такой же независимой проверки.

## Перенос между чатами

`NEW-TASKS.md`: N-ID, тип, «новая учебная задача», неизменное полное условие.
`NEW-KEYS.md`: тот же ID, подсказки, общий ключ и границы инструментальных проверок.
`PROGRESS.md`: статус N-ID и ссылка на эти отдельные файлы. При потере ключа
проверить задачу заново, а не восстанавливать вердикт по памяти. Личные попытки
и оценки не добавлять в общий корпус агента автоматически.
