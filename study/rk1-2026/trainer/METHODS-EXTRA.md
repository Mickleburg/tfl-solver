# Дополнение к памятке методов

## Как выбрать простой ход для регулярности

Сначала перепиши условие как существование частей, отметь пустые случаи и
неразличимые границы. Проверь ε и несколько коротких слов, затем выбери:

1. **Края и серии:** разность числа ab и ba определяется краями; разность
   счётчиков b^k и b^(k+1) считает длинные серии. Сначала объясни вклад одной серии.
2. **Разрез:** F(t) — левый счётчик минус правый. Концы разных знаков дают
   равенство только после проверки величины шага. Шаг 2 может пропустить ноль.
3. **Свободные части:** пустые края иногда сводят язык к простому условию,
   но в R01 они дают лишь b*. Отрицание принадлежности требует исключить
   все разбиения, а не только понравившееся.
4. **Управляемое подсемейство:** один блок b, единственное ab, выделенный
   центр палиндрома помогают прочитать условие прямо по двум показателям.
   После этого строятся различимые префиксы; полное описание L не обязательно.
5. **Скрытые арифметические параметры:** вырази НОД через видимые суммы.
   Найди достаточное условие невозможности для всех скрытых разбиений,
   затем положительную диагональ и продолжения.
6. **Одна буква:** после конечного начала путь ДКА периодичен. Растущие
   пропуски противоречат периодичности; длинные подряд принимаемые интервалы
   вместе с неограниченными пропусками тоже невозможны. Объединение проверяется
   целиком. Для разности квадратов запрет остатка 2 недостаточен — нужны
   конструкции всех остальных длин, включая 0.

Достаточно треугольной различающей таблицы: x_i z_i∈L и x_j z_i∉L при j>i.
Остальные клетки можно не вычислять. Если используешь регулярное пересечение,
обоснуй его точное равенство заявленному языку.

## Другие полезные малые шаги

Для дополнения сначала установи, какие вхождения разделителя могут быть
выбраны: в P10 это предпоследняя b, в P11 — произвольная пара b, не обязательно
соседняя. Отрицать один выбранный разбор недостаточно. По ДКА дополнение
строится сменой допуска только после детерминизации и дополнения переходов.

Префиксность кода достаточна для однозначности итерации, но не необходима.
Можно сокращать общий префикс разных разборов и перечислять достижимые хвосты.
О неоднозначности говорит достижение пустого хвоста, а не просто петля хвостов.
Для общего регулярного выражения нужно также учитывать разборы внутри блоков.

Для выражения по автомату проверь, есть ли обязательное промежуточное
состояние: первый вход · (возвращения)* · последний выход. Если такой простой
структуры нет, используй Ардена или исключение состояний.

Генерация и её проверки — GENERATION.md. Конечные тесты помогают обнаруживать
ошибки формализации, но общий учебный ответ опирается на доказательство.
