# Тренажёр РК1 по всем 12 типам

Набор для самостоятельной подготовки в отдельном чате. Условия, подсказки,
доказательства и переносимый прогресс разделены. Проходить весь запас подряд
не нужно: сначала по одной задаче каждого типа, затем работа над ошибками.
Регулярности уделяется больше практики по запросу ученика. Это не оценка
вероятностей официальных карточек и не полная база РК.

## Начать занятие

В готовом комплекте прикрепи к новому чату **TASKS.md, KEYS.md, METHODS.md,
GENERATION.md, PROGRESS.md**. Скопируй в сообщение **START-PROMPT.md**.
KEYS.md не открывай заранее, если хочешь решать самостоятельно.
README и SOURCE-AUDIT загружать не обязательно.

Чат выдаёт одно условие и ждёт попытки. Команды: `подсказка`, `ещё подсказка`,
`решение`, `карточка`, `дальше`, `повтор`, `новая задача`, `контроль`,
`сохранить прогресс`. По умолчанию ответы скрыты до запроса. Новые задачи
генерируются по проверяемым семьям, помечаются N-ID и не выдаются за официальные.
Для продолжения в другом чате перенеси прогресс и отдельные N-условия/ключи.

Личный старый прогресс приложи дополнительно, не заменяй его пустым шаблоном.
Старые T-ID сохранены. Самостоятельное освоение, просмотр решения и решение
в лимит времени учитываются отдельно. У чата нет автоматической межчатовой памяти.

## Источники и блоки

T — прежний короткий банк; P — условия PDF с указанием страниц;
R — две записи пересдачи, области переменных явно уточнены;
G — новые учебные задачи. Полная карта ID по типам находится в PROGRESS.md.

| Тип | Тема | Новый запас / прежняя опора |
|---|---|---|
| 1 | Все критические пары первого уровня | G13, T01 |
| 2 | Завершимость SRS, счётчики, бесконечный вывод | G14, T02 |
| 3 | Конечность моноида, пополнение и дерево | G15, T03 |
| 4 | Регулярное выражение по автомату | P15, T04 |
| 5 | Автомат по выражению | G16, T05 |
| 6 | Минимальность и минимизация ДКА | G17, T06 |
| 7 | Детерминизация с ε-переходами | G18, T07 |
| 8 | Пересечение ДКА | G19, T08 |
| 9 | Дополнение регулярного языка | P09–P12, T09 |
| 10 | Регулярность | P01–P08, R01–R02, G01–G12, T10 |
| 11 | Неоднозначность выражения | P13, T11 |
| 12 | Эквивалентность выражений | P14, T12 |

Формат письменной тренировки: одна задача, собственный таймер на 10 минут,
проверка заготовки после пяти минут по запросу. Точная рубрика баллов не
предоставлена; чат не ставит официальный балл и не гарантирует зачёт.
Если осталось мало времени, ограничься стартовыми представителями 12 типов
из промпта и повтором ошибок. Сложные задачи PDF оставь на дополнительный проход.

## Воспроизвести комплект из репозитория

Исходники расширения лежат здесь, T-карточки берутся из `../final-sprint/`.
Сборщик использует только стандартную библиотеку Python 3.11+:

```powershell
py -3 tools/build_rk1_trainer.py --output local/rk1-trainer-new --zip
```

Запускать из корня репозитория. Выбери новый каталог: сборщик отказывается
перезаписывать существующий комплект или архив, защищая личный прогресс.
В архив входят готовые файлы с простыми именами, дополнительных пакетов,
плагинов и доступа к репозиторию в учебном чате не требуется.
