# Подготовка к РК1: комплект для отдельного чата

## Как начать

1. Открой новый чат с выбранной моделью.
2. Прикрепи `TASKS.md`, `KEYS.md` и `METHODS.md`. При продолжении добавь
   заполненный `PROGRESS.md`.
3. Скопируй в сообщение весь текст `START-PROMPT.md` и отправь.
4. Решай выданную задачу. Команды: `подсказка`, `ещё подсказка`, `решение`,
   `дальше`, `повтор`, `контроль`, `сохранить прогресс`.

Не открывай `KEYS.md` сам, если хочешь избежать спойлеров. Он предназначен
для преподавателя-чата. Никакая установка плагина не нужна: это автономные
текстовые материалы, а не подключение к Python-оракулам проекта. Модель
не должна утверждать, что запускала их.

По умолчанию чат показывает только условие и ждёт твоего ответа. Это надёжнее
прокрутки: решение нельзя случайно увидеть. Команда `карточка` включает
условие и два отдельных спойлера; если клиент их не поддерживает, используй
пошаговый режим. Сначала пробуй самостоятельно, затем бери подсказку, а после
разбора воспроизведи доказательство своими словами.

## Тематический маршрут

| Блок | Тема | Что научиться делать |
|---|---|---|
| D | Регулярность | упрощать условие, выбирать различающие префиксы и продолжения |
| E | Автоматы | строить позиционный автомат, произведение, ДКА и дополнение |
| F | Регулярные выражения | отличать разбор от детерминированного чтения, устранять неоднозначность |
| A | Кодирование | различать инъективность, морфизм и задержку декодирования |
| B | Переписывание | выбирать меру, разбирать наложения, моделировать образцы |
| C | Копредставления и префиксные грамматики | доказывать верхнюю и нижнюю оценки числа элементов |
| G | VPL | учитывать все роли букв, ограничивать полезную память стека |
| H | Дополнительные задачи | исследовать избегание повторов без подмены доказательства перебором |

Рекомендуемый порядок: D01, D03, D02, D04, D05, D06, D15; затем остальной D,
E, F, A, B, C, G. Внутри блока — по порядку номеров. B04, C05, C06 и H —
дополнительный маршрут: не задерживай на них первый проход всей основной базы.
Для короткого занятия выбери одну новую задачу и одну задачу на повторение.
После каждого блока пройди смешанную проверку без названий методов.

Состояние «решил самостоятельно» ставится только после собственной попытки
без подсказки. Чтение готового решения не равняется освоению. После помощи
полезно снова решить ту же задачу в другой день, не подглядывая.

## Границы комплекта и происхождение условий

Комплект составлен из предоставленных копий семинарских обсуждений до
10 октября 2026 года включительно. Это база подготовки, а не утверждение
об официальном составе карточек РК или их разбалловке. Время контрольного
раунда выбирает студент; оно не объявляется официальным лимитом РК.

| Семинар | Карточки |
|---|---|
| 05.09 | A01–A04, B05, B06, B08 |
| 12.09 | B01, B02, B07, C01, C02, C05, C06 |
| 19.09 | C04, D01, D05–D09, D16–D18, H01, H02 |
| 26.09 | B03, B04, C03, D10–D14 |
| 03.10 | D02–D04, D15, E01–E03, G01 |
| 10.10 | E04–E08, F01–F08 |

Имена, аккаунты, реакции, обращения и чужие персональные данные исключены.
Исходные копии остаются отдельно в `references/delete/`; удалять их сейчас
не следует. Некоторые положения источников исправлены или оговорены:

- `10-09.md` имеет заголовок про 10 октября; здесь дата взята из заголовка.
  `19-0.md` соответствует 19 сентября.
- Восстановленные автоматы E03–E05 заданы таблицами из текстовых разборов,
  а не ссылками на пропавшие картинки. Для E03 источник — таблица произведения;
  это реконструкция исходных компонентов, согласованная с этой таблицей.
- Дополнительный ε-НКА и автомат для упрощения с допускающими состояниями
  1 и 3 из последнего комментария 10 октября остались без переходов:
  вместо картинок в копии только подписи. Эти две задачи не выдаются, пока
  не будут приложены схемы. Не путать второй автомат с E05, где допускающее
  состояние только 3.
- Разминочная SRS 19 сентября упомянута без правил. Отдельного условия нет.
- D03 и D04 — две разные записанные версии условия; обе сохранены.
- В E06–E07 речь о любых двух, а не только соседних вхождениях `aa`;
  в E07 считается ровно одно вхождение `bb`, а не промежуток, равный `bb`.
- В F02 и F08 стоит `(bb|ba)*`, в F03 — `(b|ba)*`. Подменять нельзя.
- Значение термина «почти однозначность» в F03 не подтверждено отдельным
  определением курса. Число разборов исследовано; терминологический вердикт
  допустим только после уточнения определения.
- В G01 не используется КС-лемма о накачке: наличие её в учебнике не означает,
  что она была пройдена к соответствующему семинару.
- В H01–H02 есть условия и направления поиска, но нет полного проверенного
  учебного доказательства. Не использовать их для автоматической оценки.

Комплект не переносит исторические баллы и архивные варианты лабораторных.
Его используют заранее, чтобы научиться решать и защищать решения без чата.
