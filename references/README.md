# Локальные референсы

Все тяжёлые и вложенные источники собраны под одним корнем. Содержимое
подкаталогов игнорируется Git; версионируются только производные материалы в
`corpus/` и отчёты об изучении.

```text
references/
├── teacher/FormalLanguageTheory/    # TonitaN/FormalLanguageTheory, первоисточник
├── course/TFL-IU9-claude/           # учебники, конспекты и сканы
├── chat/chat-onTG-2025-tfl/         # полный экспорт учебного чата
├── students/                        # 21 исходный студенческий каталог
└── vendor/                          # 19 дополнительных репозиториев
```

## Доверие к источникам

1. Условие, которое прислал пользователь.
2. `teacher/` — формулировки, лекции, разбалловка и ответы преподавателя.
3. `course/` — учебники и конспекты; рукописные решения требуют проверки.
4. `students/` и `vendor/` — идеи, оформление и контрольные примеры.
5. `chat/` — подсказки и контекст; ответы преподавателя выделяются отдельно.

Студенческий результат нельзя переносить в решение без независимой проверки.
Чужие репозитории сохраняют собственные `.git` и не должны добавляться во
внешний Git как gitlink.

## Производные данные

- `py -3 tools/extract_corpus.py` обновляет `corpus/txt/` и
  `corpus/INDEX.tsv`.
- `py -3 tools/extract_chat.py` обновляет безопасную предметную выжимку
  `corpus/chat/`.
- `reports/vendor-repos/NOTES.md` и `docs/01-KNOWLEDGE-MAP.md` фиксируют,
  что именно уже изучено.

Пути в скриптах относительны корню репозитория, поэтому весь каталог проекта
можно переносить без перенастройки.
