# Локальные первоисточники

Все тяжёлые источники, которые нужны только для сверки, находятся под одним
корнем и не включаются в Git или wheel:

```text
references/
├── teacher/FormalLanguageTheory/  # официальный репозиторий курса
└── course/                        # учебники, конспекты и дополнения
```

Порядок доверия:

1. полное условие, присланное пользователем;
2. `teacher/` — официальные формулировки, лекции и критерии;
3. `course/` — учебные материалы, которые требуют содержательной сверки;
4. обезличенные производные заметки в `corpus/knowledge/`.

Сторонние частные материалы не являются частью проекта. Из них допустимо
сохранять только независимо проверенные методы и тестовые случаи без имён,
дат, аккаунтов, оценок и ссылок на происхождение.

`py -3 tools/extract_corpus.py` обновляет `corpus/txt/` и
`corpus/INDEX.tsv`. Пути относительны корню репозитория, поэтому каталог
проекта переносим без перенастройки.

Официальный репозиторий курса распространяется по CC BY-SA 4.0. Атрибуция,
область производных материалов и описание преобразований зафиксированы в
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md); корневая Apache-2.0
не переопределяет лицензию этих материалов.
