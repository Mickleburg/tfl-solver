# Примеры учебного оформления

Примеры предназначены для проверки оформления и самостоятельного решения.
Математические утверждения проверяются отдельно в регрессиях; этот файл не
является результатом запуска внешней модели. Все ответы находятся в спойлерах.

## Задача 1. Детерминизация

### Условие

Дан ε-НКА над алфавитом `{a,b}`. Начальное состояние — 1, допускающее — 3.
Переходы: `1 --ε--> 2`, `1 --a--> 3`, `2 --a--> 2`,
`2 --b--> 2` и `2 --b--> 3`. Других переходов нет.
Требуется построить детерминированный конечный автомат, язык которого
совпадает с языком данного ε-НКА.

<details>
<summary>Подсказка к решению</summary>

Какие состояния доступны ещё до чтения первой буквы? После каждой буквы
сохраняй все возможные положения исходного автомата как одно множество.

</details>

<details>
<summary>Решение</summary>

Тип задачи — детерминизация ε-НКА; метод — построение подмножеств.
Начальное ε-замыкание равно `{1,2}`. По `a` переходы из этих состояний
дают `{2,3}`; по `b` получаем то же множество. Это подсказывает продолжить
построение уже от найденного множества, а не перечислять все подмножества.
Из `{2,3}` по `a` получаем `{2}`, по `b` — `{2,3}`.

| Состояние | `a` | `b` | Допускающее |
|---|---|---|---|
| → A = `{1,2}` | B | B | Нет |
| B = `{2,3}` | C | B | Да |
| C = `{2}` | C | B | Нет |

Инвариант: после каждого префикса состояние ДКА равно множеству всех
доступных состояний НКА. Он верен для пустого префикса по ε-замыканию и
сохраняется объединением переходов. Допуск определяется наличием состояния 3.
Ответ — приведённый ДКА с тремя состояниями. Минимизация не требовалась.

</details>

## Задача 2. Минимальность

### Условие

Дан ДКА над `{a,b}` с начальным состоянием 1 и допускающим состоянием 3.
Переходы: `1 --a--> 2`, `2 --a--> 1`, `3 --a--> 3`,
`1 --b--> 3`, `2 --b--> 3`, `3 --b--> 2`.
Требуется установить, является ли данный ДКА минимальным, и обосновать ответ.

<details>
<summary>Подсказка к решению</summary>

Сначала отдели допускающие состояния от недопускающих. Проверь, одинаково
ли ведут себя состояния одной группы после чтения каждой буквы.

</details>

<details>
<summary>Решение</summary>

Тип задачи — проверка минимальности; метод — уточнение разбиения состояний.
Начальное разбиение: `{1,2}` и `{3}`. Из 1 и 2 буква `a` ведёт в первую
группу, а `b` — во вторую. Разбиение устойчиво: по индукции по длине
продолжения состояния 1 и 2 дают одинаковый результат допуска.
Значит, их можно объединить в X; состояние 3 обозначим Y.

| Состояние | `a` | `b` | Допускающее |
|---|---|---|---|
| → X | X | Y | Нет |
| Y | Y | X | Да |

Оба состояния достижимы: X по ε, Y по `b`. Пустое продолжение различает
их по допуску. Ответ: исходный автомат не минимален; минимальный
эквивалентный автомат имеет два состояния.

</details>

## Задача 4в. Степень неоднозначности

### Условие

Дано регулярное выражение `(a|ab)*(b|ba)*` над `{a,b}`.
Требуется установить, ограничено ли число разборов всех слов общей
константой, и является ли выражение почти однозначным. Здесь почти
однозначность понимается как сублинейный рост максимального числа разборов.

<details>
<summary>Подсказка к решению</summary>

Проверь, можно ли перемещать границу между двумя частями выражения.
Если это возможно на коротком слове, попробуй повторять его фрагмент.

</details>

<details>
<summary>Решение</summary>

Тип задачи — оценка неоднозначности; метод — семейство свидетелей и оценка
числа границ разбиения. У `ab` два разбора: `a · b` и `ab · ε`.
Различаются границы двух частей. Повторение фрагмента даёт
$w_n=(ab)^n$, $n\ge1$. Для каждого $0\le k<n$ имеем

$$w_n=\underbrace{(ab)^k a}_{\text{левая часть}}
       \underbrace{(ba)^{n-k-1}b}_{\text{правая часть}}.$$

Ещё один разбор относит всё слово к левой части. Других границ нет:
после внутренней `b` остаток начинается с `a` и не подходит правой части.
Итого $n+1$ разборов при длине $2n$; общей постоянной границы нет.

При фиксированной границе разбор каждой части единственен: слева `b`
обязательно входит в `ab`, справа `a` обязательно входит в `ba`.
У слова длины N не более N+1 границ, а семейство даёт линейную оценку снизу.
Ответ: рост равен $\Theta(N)$; выражение не конечно неоднозначно и не почти
однозначно при указанном соглашении.

</details>

## Задача 4г. Однозначность

### Условие

Дано регулярное выражение `((a|aa)b|abaab)*` над `{a,b}`.
Требуется установить, является ли это выражение однозначным: имеет ли
каждое слово его языка единственный полный разбор, и обосновать ответ.

<details>
<summary>Подсказка к решению</summary>

Сравни длинный блок с последовательностью более коротких. Можно ли получить
одно слово за разное число повторений?

</details>

<details>
<summary>Решение</summary>

Тип задачи — проверка однозначности; метод — поиск двух разбиений на блоки.
Одна итерация даёт `ab`, `aab` или `abaab`. Длинный блок начинается с `ab`;
после удаления этого префикса остаётся `aab`, тоже разрешённый блок.
Поэтому `abaab = ab · aab`: один разбор использует одну итерацию, другой — две.
Ответ: выражение неоднозначно; свидетель — `abaab`.

Для $(abaab)^n$ каждый из n повторов независимо разбирается длинным блоком
либо двумя короткими. Это даёт не менее $2^n$ разборов. Два конкретных разбора
уже доказывают отрицательный ответ; конечный перебор для этого не нужен.

</details>
