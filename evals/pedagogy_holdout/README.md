# Педагогический holdout

Набор проверяет не только правильный глобальный класс, но и путь до основного
метода: буквальные признаки условия, малые приёмы и корректный перенос
семинарского аналога. Он отделён от замороженного `agent_holdout` v1 и не
изменяет его исторические оценки.

Восемь случаев покрывают:

- пять прямых переносов методов семинара;
- два тренировочных переноса отдельных малых приёмов;
- один полный режим с аудитом уровней инъективности.

Запуск реальной LLM выполняется только явно:

```powershell
py -3 -m tfl pedagogy list
py -3 -m tfl pedagogy prompt --case training-unbounded-delay
py -3 -m tfl pedagogy run --runner codex --case training-unbounded-delay `
  --output reports/pedagogy/codex-delay.jsonl
py -3 -m tfl pedagogy score --input reports/pedagogy/codex-delay.jsonl
```

Scorer оценивает режим, класс, аналог, наблюдения, малые приёмы, основной
метод, выбор и фактический запуск оракула, содержательные опоры ответа и
отсутствие запрещённого педагогического сокращения. Регулярные выражения
рубрики скрыты от запускаемой модели.

Версия 1 заморожена после калибровки словаря рубрики; номер её ревизии и хеш
находятся в `manifest.json`. Первый Codex baseline: 8/8 PASS и 104/104 после
ручной проверки доказательств. Полный отчёт —
`reports/pedagogy/codex-baseline-2026-09-28.md`.
